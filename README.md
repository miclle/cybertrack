# CyberTrack

双履带语音交互玩具坦克：前部微型自动水枪作为枪管，尾部自动泡泡机向后吹泡泡，ESP32-S3 N16R8 接入灵矽平台，使用大容量充电宝供电。

**当前阶段：需求与工程资料初始化（2026-10-23）。** 已整理部件资料、采购记录和方案文档；尚未完成坦克整机 CAD、固件、电路、采购定型或实物验收。

## 已确定的方向

- 只有左、右两条履带，采用低矮坦克车身；前方枪管、后方泡泡出口。
- 采用 37R-520 电机、DF-MD V1.3 双路驱动板和 track-mount 安装件。
- 电源路径为充电宝经 DC-DC 升压得到 12 V 电机驱动母线。主控、音频及效果模块分别按额定电压供电。
- 水枪通电后自行脉冲喷水；泡泡机通电后自行工作，自带风扇向后吹。
- 顶部拟布置两只火花效果模块：用户提供输入 3–6 V、单次拉弧 5 秒以内；商品称“1000KV”，实际输出规格未知。需求保留，工程集成待评估，当前不提供高压接线和驱动实现。低压灯光为候选替代方案，尚未替换原需求。
- ESP32-S3 N16R8 通过灵矽提供语音交互，所有实体动作由本地控制逻辑限时和校验。
