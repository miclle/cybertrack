# CyberTrack

CyberTrack 是一个双履带语音交互玩具坦克项目，将坦克造型、履带行走和喷水、泡泡效果结合起来。低矮车体两侧布置履带，前部自动水枪作为枪管，尾部泡泡机向后吹出泡泡。

项目采用 ESP32-S3 主控，计划接入灵矽平台，让使用者通过语音与坦克交流、发出动作指令，并使用充电宝供电。

## 规划功能

- **双履带行走**：前进、后退、差速转弯和停止。
- **语音互动**：语音对话，以及行走、喷水和吹泡泡等动作控制。
- **前部喷水**：自动水枪产生连续脉冲喷水效果。
- **尾部泡泡**：泡泡机通过自带风扇向车后吹出泡泡。
- **顶部效果**：拟加入双火花视觉效果，方案尚待评估。
