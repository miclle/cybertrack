## 原始文件与展示副本

照片和两段原始视频内容保持不变。[素材清单](media-manifest.json)保留原文件名、新文件名、画面说明、字节数和 SHA-256，可回溯并校验文件。

页面使用 `previews/` 中的轻量 JPEG 预览图，按原比例缩至不超过 1200 × 900 像素，不裁切画面；点击预览图可打开原图。

两段播放器均使用 GitHub 附件，保持完整时长与音轨。长视频副本保留原 H.264 / AAC 流，不重新编码，只将 MP4 索引前置并将 H.264 level 标记从 6.0 修正为 3.1。短视频副本将 HEVC 转为 H.264，保留 1280 × 720 分辨率、30 fps 与原 AAC 音轨，并将 MP4 索引前置，以改善浏览器播放兼容性。

影像展示制作过程与当时样机表现；画面不能确定具体固件版本、供电配置、电流、温升或停止时延，不替代[项目验证记录](../docs/verification-plan.md)。
