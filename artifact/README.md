## 原始文件与展示副本

照片和两段原始视频只做重命名，内容未改动。[素材清单](media-manifest.json)保留原文件名、新文件名、画面说明、字节数和 SHA-256，可回溯并校验文件。

首页播放器使用同一长视频的 GitHub 附件副本：保留完整时长、画面和音轨，不重新编码；只将 MP4 索引前置，并将 H.264 level 标记从 6.0 修正为与该分辨率、帧率相符的 3.1。原始视频保留在本目录。

影像展示制作过程与当时样机表现；画面不能确定具体固件版本、供电配置、电流、温升或停止时延，不替代[项目验证记录](../docs/verification-plan.md)。
