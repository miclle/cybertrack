# 固件规划

当前没有可编译或可烧录固件，未控制任何实体硬件。

候选框架为 ESP-IDF，主控已指定 ESP32-S3 N16R8，见[采购记录 P07](../hardware/procurement.md)。具体开发板修订版、原理图、音频器件和 GPIO 尚未确定，Flash／PSRAM 配置需与实物核对，故暂不锁定 SDK 版本或创建虚假的 board 配置。

实现顺序：本地停止与默认关闭 → 电机和效果模块单项台架 → 音频与联网 → 灵矽只读状态 → 受限动作工具 → 故障与组合负载测试。模块职责见[架构](../docs/architecture.md)，消息和工具边界见[灵矽接入方案](../docs/linx-integration.md)。

后续初始化工程时记录构建环境、依赖版本、板型、电源与引脚映射、编译／烧录／恢复命令。高压模块驱动不属于当前实现范围。
