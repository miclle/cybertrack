# 开发板资料最小清单（Q06 / F2b）

更新：2026-10-23。已知主控采购描述为 ESP32-S3 N16R8，原[采购记录 P07](../hardware/procurement.md)已有商品链接；具体开发板型号、修订版及实际所选规格尚未确认。无需重新提供同一商品链接，优先补以下材料。

## 第一批：足以开始核对板卡与下载工程

| 资料 | 最少提供内容 | 用于确定 |
|---|---|---|
| 实购选项与完整板名 | 订单所选规格文字、厂家、型号／修订版；订单截图可遮住姓名、地址、订单号等信息 | 避免把同页不同版本当作同一块板 |
| 实物正反面照片 | 看清模组／芯片金属罩丝印、PCB 版本、排针标注、USB 口和按键；有多个接口时一并拍清 | 对应原理图、模组版本与连接接口 |
| 对应版本原理图与引脚图 | 厂商 PDF、产品说明或资料链接；没有时直接写“暂无” | 电源入口、板载连接、引脚占用、默认电平和启动条件 |
| Flash／PSRAM 资料 | 实际模组完整丝印；厂商标明的容量、接口模式及电压信息（如资料中有） | 选择存储配置；仅“N16R8”商品标题不足以冻结全部设置 |
| 下载与复位说明 | 厂商说明哪个 USB 口用于下载／串口、BOOT／RESET 用法；若已经连接电脑，附系统识别到的端口名称 | 下载通路、串口、复位／恢复流程；不要求现在烧录或擦除 |

没有单独的内存手册时，先发完整模组丝印和板卡原理图即可继续查证，不需要自行猜 QSPI／OPI 等配置。没有原理图不必补画或猜针序，但相关 GPIO 工作仍需等待可核实资料。

## 第二批：开启真实本地停止输入前

| 资料 | 最少内容 | 解锁的工作 |
|---|---|---|
| 本地使能与停止器件 | 准备用板载按键还是外接按键；已有器件型号／照片；尚未决定则注明 | 按键资源、输入极性和去抖设计；不默认占用启动按键 |
| 独立停止方案 | 是否已有切断执行器供能的开关／电路，其型号与额定资料；仅软件按键不等于供能切断 | 停止接口与默认关闭的实物验收计划 |
| 主控供电与当前连接 | 计划用哪个接口供电；目前是否接了扩展板或其他外设，分别是什么；若未连接则注明 | 避免供电冲突和已占用接口误分配 |

这部分不用现在提供具体 GPIO 编号。我会根据对应版本原理图核对可用资源，再形成引脚表。

## 可以稍后补，不阻塞无音频启动

麦克风、功放、扬声器的具体型号；开发板尺寸／安装孔用于机械适配。电机、MOS、继电器及液体模块资料用于 F3 单模块台架，不要求为了建立无负载启动工程一次补齐全部 BOM。

ESP32-S3 的下载连接可能通过 USB 外设或 USB 转串口桥，具体应以开发板资料确认，见[乐鑫串口连接说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/get-started/establish-serial-connection.html)。不根据 USB 接口外形或通用芯片资料推定这块板的走线。

## 收到资料后的交付顺序

1. 对照实物和原理图形成版本化板卡记录，列出已确认与未知项。
2. 再选择并固定 ESP-IDF、Flash／PSRAM、下载和恢复配置；保留执行器能力全零。
3. 实现真实时钟、输入、输出关断和看门狗适配，检查构建内存占用。
4. 经授权的实物验证记录复位／启动默认状态、停止输入、实际任务延迟、看门狗行为和关断结果；通过后再进入各自负载台架。

不要把主机运行层检查或成功编译记为实物停止、电气或使用安全验收。
