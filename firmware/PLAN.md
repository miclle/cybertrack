## 通用核心实现记录与下一步

以下测试计数、资源占用与通过结果是对应离线验证报告的历史记录，本次文档同步未重新运行这些测试。通用核心的单槽互斥、本地授权及持久化契约与当前面包板控制策略分开维护。

F0 覆盖八组场景：上电／复位、动作期限与互斥、停止与故障恢复、会话与重放、非法参数、无配置能力关闭、计时异常、方向及边界。结果只证明电脑进程中的逻辑行为。

F1 已完成 24 个协议测试方法及其中的参数子用例、500 次确定性消息变异。包含严格整数校验、16 槽 FIFO 原响应缓存、32 KiB 启动期防重放过滤器、停止优先与使能代次检查。过滤器跨连接保留，旧动作 ID 在响应淘汰或重新使能后仍不能执行；只读请求持续处理。碰撞会保守拒绝新动作，真实流量容量和服务端 ID 兼容性仍待 F4 评估。

解析资源故障已补齐：默认分配路径不变，增加启动期可选分配器；新解析或缓存重读内存失败撤销逻辑输出并要求本地重新使能，原缓存与序号不变。主机测试包含 17 类请求、138 次逐点注入、20 次连续失败和假板卡关断联测。CTest 23/23 通过；测试样本中临时 JSON 请求字节峰值 41736，协议对象 137448 字节，均为该次主机 ABI 观测值。

F2a 已完成[通用启动与运行层](RUNTIME.md)：先关断再自检、本地使能边沿、周期期限与调度检查、输出应用及失败关断、条件喂狗、运行层故障锁定；现有 16 组假板卡场景通过。新增与电平无关的输入去抖／已观察脉冲锁存（5 组测试），以及 4 槽完整消息接收队列（4 组测试）。该 F2a 通用运行层尚未完成真实线程、定时器、中断捕获、ESP-IDF、GPIO 和硬件看门狗适配；F2b 无负载工程与面包板工程的实机结果另行记录。

接收边界与连接流程已完成[离线实现](TRANSPORT.md)：回调切片与 TEXT／CONT 消息组装、首片元数据保持、连接／握手／分片／发送期限、退避重连及旧事件隔离、发送失败关闭。14 组假传输场景与 376 个穷举切分用例通过；此通用传输层的真实 TLS、hello 校验及 SDK 事件映射仍待接入；独立联网与面包板已有真实联网记录，不混记为通用层移植完成。

长时会话已完成 5 组压力场景：163522 次协议调用、20000 个动作意图、100000 次状态查询、500 次恢复及 40502 次重放检查。无旧动作重新执行，临时分配台账归零；虚拟时钟推进 120520500 ms，不是实际运行时长。误拒绝与饱和边界见[测试记录](tests/README.md#长时会话与缓存压力)。

通用核心后续接入仍按下表保留待验收项；F2b 已有供应商原理图、排针、尺寸和无负载烧录／启动证据，完整适配仍需确认实物版本与焊装。移植前需核对板级内存与任务调度：当前主机协议适配器对象约 134 KiB，解析器仍使用堆分配。F4 已在独立状态／停止工程接入真实 TLS 及平台令牌鉴权；动作所需的认证新鲜度证据源和实际持久化后端仍未实现，正式控制核心动作保持关闭；独立水枪台架仅接受本机预先创建的一次性固定意图，边界见 [0.2.0 实测](../docs/linx-validation.md)。

Q06 的供应商原理图／排针、存储标称和下载通路已补齐；正反面、实测外形、模组丝印、USB 枚举及存储识别已补齐；仍需板级修订版、焊装和天线核对、停止器件，分批清单见[开发板资料](BOARD-INFO.md)。电机与喷水已有上述分项台架结果，泡泡已有运行影像；仍需补齐各模块参数、定量测量及失效记录。总体验收仍以[实施及验收计划](../docs/verification-plan.md)为准。
