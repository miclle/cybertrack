# CyberTrack A3 双编码器采集

在此目录运行 `pio run` 构建 U19 采集程序。J20 接支持 SWD 的工装，目标板自供电，1 脚为电平参考。S3 首板诊断程序用 ESP-IDF 在相邻的 `esp32-a3-feedback` 目录运行 `idf.py build` 构建。台架先断开 SW2，确认编码器供电和针序，再手转车轮。诊断程序使用 GPIO41/42 上的 100 kHz I²C 总线，通过原生 USB 打印原始计数和六轴数据。[板端接口与 IMU](../../hardware/pcb/motion-feedback/README.md)

## 从机协议

7 位地址 0x32。一次直接读 17 字节，每次从机收到读地址均锁存一帧。短读可提前 NACK，下一次读从头开始。所有多字节字段为小端。

| 偏移 | 长度 | 内容 |
|---|---:|---|
| 0 | 2 | ASCII CT |
| 2 | 1 | 版本 1 |
| 3 | 1 | bit 0 为上电或复位待确认 |
| 4 | 4 | 本次启动后的毫秒数，模 2³² |
| 8、12 | 各 4 | 对应 J18、J19 的累计增量，模 2³²，可按补码显示负转数 |
| 16 | 1 | 前 16 字节的 CRC-8，初值 0，多项式 0x07，最高位先行，无末尾异或 |

主控先校验长度、版本和 CRC。发现复位标志或超时后撤销旧的闭环目标并重建基准；停稳后用独立的两字节写事务 `A5 5A` 加 STOP 确认复位标志，再读回核对。这个命令只清标志。两次有效帧间用模差求左右增量和时间差；超过采样时限、时间差为零或超出实测最大速度的增量应丢弃。首件诊断保留复位标志供观察。TIM1/TIM3 的输入滤波和 AB 相序需以实测速度和波形验证；主板运动控制另行集成。
