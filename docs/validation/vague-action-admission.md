# 含糊动作的首次执行门禁

ct68 针对历史 V079“动一下那个东西”被模型猜成前进，增加设备端首次执行约束。它是未部署的源码候选，最近记录板上仍为 ct45；十二项公开工具与 5991 字符角色源均不变。[构建记录](../../firmware/esp32-audio/verification-ct68.json)

## 机制与保留能力

实际 STT 到达后，设备在同一控制锁内推进输入代际并记录是否命中有限的泛化动作类别。包含“动／转／开／启动／弄／效果／做点什么／来一下”，同时没有命中约定动作、方向、速度或兼容别名词时，执行器和调速回调返回 `action_unspecified`，附 `clarification_facts` 要求澄清而不猜测前进、不换工具补做。本次请求不改变已有输出或截止时间。失败仍触发已有同输入隔离，新 STT 重新计算，旧排队回调不能绕过新输入。

草稿 compose 不启动执行器，继续按原有查询、版本、允许步骤和网页显式确认约束工作，保留让 AI 设计表演的能力。ct67 的无量化相对改稿约束仍优先检查，因此“第二步动作短一点”不能借 compose 猜时长。查询、立即全停和具有原权限的网页控制保留；拒绝一次语音请求不会擅自停止已有动作。

本项没有实现通用意图理解：未识别表达仍走原路径；命中方向或动作词只交回既有契约，不代表设备理解了意图。否定、引用、人物名字、多个分句的词语归属和上下文指代尚未解析。“饭店”只在此层交回既有角色的有限识别纠错，不由门禁推断点火。比如“不要让它动”若被模型错误调用 stop，本项不会覆盖全停。草稿编辑的意图正确性也仍需原语义回归。

## 原生控制验证

二十六组运行实际 MCP 分发、实际回调与守卫，输入／时钟模拟，板级 IO 未接入：

- 泛化动作、只给时长但缺方向、首次换用水／泡泡／点火／狂暴／序列，均拒绝猜测执行。
- 同输入补做被隔离；新明确口令恢复。空白输入不能清标记，旧排队动作不能跨代执行。
- 查询不停止已有行走；泛化调速不改变 70% 速度；拒绝后仍立即全停，观察至 60 秒不恢复。
- 新建和修改创意草稿可保存且零启动；明确方向、880 ms 默认转向、泡泡与“开枪”别名保留。
- 将历史 V079 的真实 RPC 参数与时刻配合模拟识别文本回放，原先前进请求被拒绝。它是离线历史对照，不是新模型或 ASR 成绩。

当前二十六组通过；冻结 ct67 主机在同一矩阵中十八组不满足新增约束。ASan／UBSan 分类器和实际 Reply 测试另核对语音拒绝后的可信网页、全停及新输入恢复。[当前回放](evidence/ct68-vague-action/native-replay.json) · [旧版对照](evidence/ct68-vague-action/native-baseline.json)

## 二十条真实 STT 会话

预先声明十条输入、两轮各采一次，发送合成普通话 Opus，不发送原话文本、不接麦克风／扬声器／真实设备。实际收到的 STT 开启主机输入代际，模型读取实际 MCP 回执。

- 正常结束、规范化逐字转写、同观测时刻预期终态均为 **20/20**；完整 RPC 回执与终态均可复算。
- 严格工具调用 **16/20**。第一轮 A002 多查一次状态；第一轮 A004 和第二轮 A002／A004 猜测动作，均返回 `action_unspecified`。模型的错误请求仍按失败保留，不因拒绝有效而计作语义通过。
- 八条泛化请求均零启动，三次真实在线猜测执行被拦截。明确方向、泡泡、“开枪”与默认右转口令均正确调用。
- 两条停止均调用全停，但仍播报“动作都停下了”；成功静默与部分过程表达仍待修。此处仅检查平台 TTS 文本，不代表扬声器听感。

[逐条审阅](evidence/ct68-vague-action/platform-review.json) · [文件与主机摘要](evidence/ct68-vague-action/experiment.json)。预期终态在捕获的观测时刻比较，避免将已到期的短动作和刚开始的参考动作误比；严格调用另外核对动作参数。没有替换原固定八十条、八条编排或二十条真人验收成绩。

最终十五组本地检查通过，含 86 项改进测试；完整 ESP-IDF 5.5.1 构建为 2,715,712 字节。未刷写，部署与现场验收仍待完成。
