## 版本与观察边界

最近独立核验的部署是 [ct74](../ct74-deployment.md)，源码候选为 ct75。本组 HTTP 状态没有运行版本字段，未通过串口重新读取版本，也未重启或刷写设备。按主机 UTC 减设备 uptime 估算的开机时刻，相对部署记录偏移约 613 秒；可能涉及期间重启或时钟变化，原因未确认，不能把部署时的启动身份直接沿用到本轮。采集器在本组响应间比较内存中的启动标识及启动计数，未检测到变化。

本轮补充的是实际设备的**单网页草稿路径**，没有完成有效版本的表演确认与实际执行、语音／网页并发改稿、真实 Wi-Fi 断开或 300 秒草稿到期。2.3 秒是主机等待时长，不是输出关断或机械停止时延；逻辑零输出也不是物理电平测量。完整 I04／I06 与家庭体验仍有缺口，ct75 的 HTTP 零转义修复没有因本轮而获得部署验收。
