# 四路组合、点火别名与成功确认播放

ct73 将已有播放匹配扩展到行走、喷水、泡泡、点火四路，复用同一份效果别名表。它不产生动作、不修改工具参数，也不放宽设备限制；原十二项工具及 5991 字符角色保持不变。候选未部署，最近记录的板上版本仍 ct45。

## 既有动作的完整语句匹配

支持原“同时／并／和”和“先／然后／再／接着”的先后语法，完整消费原话后核对工具、每步各路时长、方向及默认速度。喷水／发射／开枪／射击、吹泡泡／开炮、点火／放电／闪电／护盾／打火／电击可出现在组合或序列中，效果前可用一个“开启”。

一步仅行走加喷水仍要求 `move_and_water`；涉及点火或其他多路组合用 `sequence` 一次提交。序列每步五字段、全部步骤及可选默认速度均须匹配。回执核对首步各活动通道的独立时长与语音来源、方向／速度，以及当前序列第一步、步数和运行状态；不能用通用最长时长代替分路事实。后续步骤不继承前步时长。

只有一步内一个明确时长时，未量化通道按既有规则共享；共享后点火超过 5000 ms 则保留音频，避免隐藏上限说明。喷水／泡泡仍最多匹配 30000 ms，行走超过本白名单的 30 秒仍保留音频，执行器原有控制能力不变。

“饭店”纠错继续限独立短句，不扩展到组合；狂暴模式与其他动作混合、重复同通道／同义词、疑问、否定、引用、未知语法及不完整表达保持可播放。它不是执行用自然语言解析器，实际动作仍由灵矽与设备守卫处理。迟到回执、额外工具或提前播报不能授权静音。

## 定向实际 STT：12 条一次采集

[语料](four-lane-feedback-cases.json)与[事先计划](evidence/ct73-four-lane/plan.json)在采集前冻结。每条只采一次，不补跑或替换失败；使用固定实际 MCP 主机，没有设备、麦克风或扬声器 IO。平台前后只读回读原模型、角色与参数一致，没有保存配置或重启。

F001 开枪加护盾、F002 四路独立时长、F003 放电后开炮、F008 行走后泡泡加护盾、F009 前进并射击，共新增抑制 277 包。明确停止沿用旧策略，36 包保持抑制。两条否定／引用与状态查询均没有新增静音。

两条失败不关闭：

- F004“前进十秒并点火”，按共享与限幅应为前进 10000 ms、点火 5000 ms，模型却请求点火 1000 ms，仍计参数失败，64 包保留。
- F010“喷水三十秒并护盾五秒”被转写为“喷水三十秒并互顿五秒”，模型只调用 water、遗漏点火，仍计识别／语义失败，79 包保留；没有增加此类同音纠错。

F011 虽正确将点火十秒限制为五秒，245 包中仍有上限说明与过程文字；它们全部保留，不能称为简短回复已通过。原完整 80／8 模型成绩不变，不能用本轮 10/12 替换。

## 软件与既有轨迹回归

普通及 ASan／UBSan 原生夹具覆盖 70 次成功匹配、87 次保留提示，包括全部 15 种通道子集、别名与顺序、共享时长、点火上限、后续默认时长、来源与时长不符、缺字段和回执代际。旧 ct72 在同组新夹具中失败。已有 ct72 单项别名／模式夹具继续通过。

原 88 条实际 STT 轨迹逐例计数保持：1085 包抑制、4595 包允许播放，81 条不一致全部保留；旧二十条轨迹及三十条组合／速度变体继续通过。ESP-IDF 5.5.1 完整编译及 18 组统一检查通过，含 124 项 Python 测试。这里的包级结果不证明真实扬声器听感或动作效果。

## 复现

```sh
python3 scripts/verify_improvements.py --source build/xiaozhi-ct73-src
python3 scripts/review_four_lane_feedback.py \
  --directory docs/validation/evidence/ct73-four-lane \
  --host /path/to/frozen/ct73/firmware_host \
  --before /path/to/ct72/feedback-replayer \
  --after /path/to/ct73/feedback-replayer \
  --output output/ct73-four-lane/review.json
```

固定主机来源与各文件摘要随证据提供。旧播放器可从基线 `bd3a424` 的 `voice_feedback.h`、`spoken_playback.h` 与当时的时长解析头文件编译；新播放器使用当前头文件和 `scripts/replay_lingxi_feedback.cc`。重跑完整控制与包级比较需要 checkout、工具链及对应二进制，不包含在纯文本参考包中。
