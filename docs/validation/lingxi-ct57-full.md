# ct57 工具定义的完整平台回归

本轮固定测试 80 条语义用例和 8 条编排用例，输入为附带前置场景的文本。平台工具定义从 ct57 prepared 源码导出，角色为已保存回读的 5991 字符版本，模型配置为 deepseek-v4-flash。每条独立建立会话，未完成会话保留原始记录，不当成“没有调用”而得分。

模型调用由静态隔离夹具应答，轨迹中的 `fixture_version=ct45` 指夹具契约。ct57 的真实控制守卫、拒绝回执和播放策略另有[主机及语音对照](admission-envelope.md)。本轮成绩描述工具选择、参数与调用顺序，真人拾音、扬声器和执行器效果另行验收。

两组完整轨迹与评分位于[回归证据目录](evidence/ct57-full/full-suite-scores.json)，历史[5991 字符角色基线](lingxi-role-5991.md)保持独立。相同用例的每次平台调用均单独计入本轮，定向复测不会改写固定集成绩。

## 本轮成绩

88 次均正常结束。语义组 77/80（96.25%），编排组 5/8。两组禁止动作样本均没有请求控制动作，八条明确停止均直接全停。成绩按完整调用顺序核对，包括多查或漏查状态。

| 用例 | 实际偏差 |
|---|---|
| V024，吹泡泡六十秒 | 请求 60000 ms，超过 30000 ms 上限，却回复最多三十秒；固件参数校验会拒绝此请求，静态夹具的模拟接受不构成固件接受 |
| V053，你现在在做什么 | 没有查询就回复待命 |
| V065，不要放电 | 额外请求状态，未请求动作 |
| C001，新建两步表演 | 只查询状态，没有保存草稿却回复“草稿已保存” |
| C004，取消草稿 | 未在本轮实际查询，直接使用输入场景中的版本 7 取消 |
| C008，第二步短一点 | 额外查询并播报推理文字，最后才询问具体秒数；未编辑或启动动作 |

ct45 工具配相同角色的历史基线为 78/80、7/8，本轮为 ct57 工具配静态夹具的单次完整回归。两轮差异同时受到工具描述、采样与会话不稳定性影响，当前不足以单独判定某次修改导致回退。定向调速与拒绝解释通过，仍不能代替完整编排及回复语义达标。

下一步优先处理 C001 的无保存回执却声称完成、V024 的越界请求，以及 C004 从场景文字代替真实查询。C008 的推理播报也保留为失败。真人与物理验证的完成条件继续按原计划执行。
