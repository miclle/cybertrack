# 组合、序列与目标速度的成功确认

ct63 扩展端侧播放匹配，让已接受的普通动作少重复播报确认。它只决定是否播放远端音频，不创建动作、改写工具参数或绕过控制守卫。最近记录部署仍是 ct45，本页是候选构建和离线回放证据。

## 完整语句与成功回执同时匹配

播放白名单按完整原话识别前进、后退、左转、右转、喷水和吹泡泡，可用“先／然后／再／接着”表达先后，用“同时／并／和”表达同一步动作，最多 16 步。支持中文或英文逗号及已有时长写法；时长为 1–30000 ms。未说时长时，全速左右转 880 ms、其他动作 1000 ms；同一步只有一个明确时长时共享，后续步骤不继承前步时长。更长行走与其他语法沿用控制能力，播放判断保留音频。

同一步不能重复同一通道。否定、问句、引用、草稿要求、点火、超限或未完整消费的原话均不进入本白名单。它不承担自然语言动作执行，灵矽仍按角色及工具契约理解请求。

目标速度支持“调到百分之六十”“速度调到 80%”“减速到60%”等明确 60–100 整数目标。“掉到百分之六十”是本次真实 ASR 转写，仅用于播放匹配，并要求带百分比；不会新增或更改任何动作别名。

原话确定预期后，还须核对本次唯一工具、所有步骤的方向、时长、通道与默认速度，拒绝额外／重复字段、拆单、遗漏步骤和时长变化。回执必须 `accepted`、`fault=none`、操作匹配；组合核对各路接受时长与语音来源，序列还须为语音来源、第一步运行、步数一致，目标速度须与接受值一致。回复早于成功回执时保留音频；后续工具调用解除当前抑制，新输入或迟到回执不能授权旧一轮。
