# 家长改稿时，小D什么时候开始说话

“结尾的泡泡短一点”需要追问秒数。“改成三秒”则应在收到保存回执后说明改动，让家长预览。为区分这两种情况，在同一线上角色与 ct45 固件主机回执下，对比了两组各九次独立文本会话。对照复用前次三轮轨迹。实验组仅在查询与改稿工具的说明开头增加“静默查询、收到回执再用中文回答”的约定。语料、角色与主机程序的哈希相同，实验说明只用于隔离工具发现，未写进机器人固件。[完整说明差异、配置与逐轮回复](evidence/draft-narration/comparison.json)

| 观察项 | 原工具说明 | 增加说明 |
|---|---:|---:|
| 明确改稿时，主机发出保存回执前，平台已返回首个音频包 | 6/6 | 6/6 |
| 待播文字含连续英文单词的会话 | 2/9 | 1/9 |
| 改三秒／删除／追问的回复字数中位数 | 140／105／55 | 118／64／18 |
| 按要求改时长、删除或保留草稿，主机零启动 | 9/9 | 9/9 |

实验组三次含糊请求都用一句中文询问时长。明确修改时仍有内部操作说明，包含一次英文和一次原样说出 `bubbles_ms`。字数包含标点与拉丁字符；英文计数识别相邻的英文单词，字段名另行审阅。两组分时运行，每种说法各三次，尚不能据此估计总体发生率。此次不采纳整段工具说明改写。

灵矽角色页中，DeepSeek V4 Flash 的思考选项已显示 `{"type":"disabled"}`。本轮保留现有模型配置。对于平台集成，需要分别观察工具中间轮文本、最终结果文本和音频事件；把语音只交给最终结果仍需保留缺信息时的追问、真实拒绝与失败。此测试仅能看到平台送达的内容，无法判定内部哪个环节产生了旁白。高级参数的含义与保存流程见[灵矽智能体配置指引](https://linx.qiniu.com/docs/xrobot/guide/agent-config)。

## 离线核对

在项目根目录使用 Python 3.10 或更新版本运行。脚本按事件顺序将合成语句和首个音频包与成功保存回执对齐，拒绝不完整会话及缺失的语句边界。无保存回执的追问记为 `null`。设备并未播放本轮音频，现场听感单独验证。

```sh
python3 scripts/review_draft_replies.py \
  docs/validation/evidence/role-5991/edit-variants-*.json.gz \
  docs/validation/evidence/draft-narration/prefixed-*.json.gz
```
