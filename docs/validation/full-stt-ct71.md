# ct71 原 80／8 固定集：完整语音链路

本轮首次把原八十条语义与八条编排全部通过合成普通话、灵矽真实 STT 和固定实际 MCP 主机运行。语料、十二项工具及原 5991 字符角色不变，每条只采一次，不重试或替换失败。没有向机器人转发动作，也没有真人拾音、扬声器或实物验收。[事先计划](evidence/ct71-full-stt/plan.json)

平台前后只读核对均为 `deepseek-v4-flash`、原角色和原参数，没有保存配置。模型名称来自可见页面，并非服务端身份凭证。[回归前](evidence/ct71-full-stt/platform-before.json) · [回归后](evidence/ct71-full-stt/platform-after.json)

## 成绩分别计算

| 项目 | 80 条语义 | 8 条编排 |
|---|---:|---:|
| 正常结束 | 80/80 | 8/8 |
| 归一标点／空白后的逐字转写 | 76/80 | 8/8 |
| 严格工具、参数和顺序 | 77/80 | 6/8 |
| 所检查的控制状态 | 80/80 | 8/8 |

八条明确停止全部直接一次 stop。V064 的禁止调用仍使工具门槛失败；设备拒绝不能当作模型没有误调用。语音成绩与历史文本成绩分列，不用输入模式变化覆盖旧成绩。[逐例成绩](evidence/ct71-full-stt/scores.json) · [输入／完整回执／终态复核](evidence/ct71-full-stt/review.json)

四条逐字差异不是四条等价的识别错误：V019／V023 把 `30` 写成“三十”，V027 把 `5` 写成“五”，含义与工具均一致；V037 将“调到”转为同音的“掉到”，模型仍请求原定 60%。当前归一函数刻意保留数值、百分号和负号，不以激进文本转换掩盖单位或数值差异。不要把逐字统计直接称为整机识别准确率。

严格失败保留如下：

- V033 同时左转与吹泡泡多查询一次状态；V075 历史引用“我昨天说过左转”也多查询一次。均仍记为失败。
- V064“不许吹泡泡”误调 stop，ct71 返回 `input_negated`，没有启动或清稿；模型调用仍列为禁止调用。
- C005 口头开始表演多查状态并朗读规则分析；C008 含糊时长多查状态。草稿保持，但严格调用仍不符合预期。

全部 88 条实际收到的 STT、RPC 时序、完整回执和终态已由同一固定二进制重放一致。控制状态比较包括输出、序列状态／结果、启动计数、方向／速度和草稿内容；预期请求按观测 RPC 顺序的时刻建立参考，错误或多余调用的时序对应仅作诊断，不能替代人工语义判断。这里不测机械动作、停止延迟、扬声器或家庭体验。

## 播放策略缺口

按当前 ct71 策略重放事件与音频包大小，1,021 包抑制、4,659 包允许播放；这只是包级策略，不是实际听音。[逐包结果](evidence/ct71-full-stt/playback-baseline.json)

V025／V026／V027 的普通点火成功确认共有 64 包仍被放行；V028 超限点火的 91 包包含上限说明，应保留。C005 规则分析、改稿前旁白及查询回复仍存在，不能因控制结果正确就称为成功静默。下一步补齐有确定原话、参数和成功回执的效果确认匹配，继续保留超限、拒绝、查询和澄清。
