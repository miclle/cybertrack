# 停止后，小D 还会不会再说一句

家长或孩子说“停止喷水”“取消序列”后，设备收到全停成功回执，ct51 会抑制随后的远端确认音频。取消未开始的草稿仍需反馈，让家长知道草稿是否保留。设备使用识别到的完整短句、对应工具和该次调用的回执决定是否静默。故障、缺失字段、过早到达的回复及多工具调用保留语音。[固件与构建记录](../../firmware/esp32-audio/verification-ct51.json)

2026-10-31，使用线上 5991 字符角色与 ct51 导出的十二个工具，向灵矽发送用户原话。16 次独立会话均正常结束。工具由隔离夹具应答，没有转发到面包板。对同一份平台轨迹分别运行 ct50、ct51 的设备播放策略，按真实顺序送入识别文字、工具回执、TTS 边界与每个远端音频包。只保存包的大小和时刻，回放时核对总字节数。

| 原话及对照 | ct50 主机回放 | ct51 主机回放 |
|---|---|---|
| 固定集八条明确停止原话，均一次全停 | 2/8 整段静默，抑制 74 包、放行 226 包 | 8/8 整段静默，抑制全部 300 包 |
| 另测“取消序列”和“取消正在执行的表演” | 两句均可播，共 80 包 | 两句各请求一次全停，80 包全部抑制 |
| 取消未开始的草稿／要求继续 | 分别放行 73／46 包 | 同样全部放行。取消草稿实际先查询再取消；要求继续时没有发起工具调用 |
| “前进！”“全部停止。”“吹泡泡！” | 三句均静默 | 三句均静默，抑制全部 74 包 |
| “让水枪喷四十秒” | 限幅提示可播 | 只请求 30000 ms，34 包全部放行。此次只回复一次“喷水单次最多三十秒。” |
