# ct77：普通测距滴声连续确认

2026-11-01 用户反馈测距偶发误判、滴声太吵，并选择“保留提示，连续多次近距才响，过滤偶发跳值”。随后用户明确授权刷入 ct77 试听，已完成仅应用部署，源码与最近记录部署均为 ct77；没有发送执行器动作。

普通提示须连续 3 个不同采样时刻的有效读数均小于 500 mm。约 100 ms 采样时，从第一个近距样本到确认约 200 ms；这是采样逻辑时间，不是实测扬声器延迟。5 ms 控制循环复用同一快照不重复计数。达到 500 mm、无效、未采样或过期时立即撤销提示资格，并取消尚在队列的普通事件；重新靠近须重新确认。相邻样本时间倒退或间隔超过 500 ms 也重新确认。

确认后沿用 400／800 ms 节拍，距离区间切换及重新确认不重置已有节拍，不补播错过的声音。对话期间继续暂缓普通滴声，语音播放队列与紧急停车告警沿用 ct74 路径。原始距离仍用于网页、语音查询和前进保护；不足 150 mm 的有效新鲜读数仍立即锁定／停止前进，至少 200 mm 解锁不续走，停车三连音不等待三个样本。角色源、工具参数、GPIO 和电源方案均未改。
