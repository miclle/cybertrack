# 和小D开始第一次互动

这张卡面向家长陪同的亲子体验。当前为开发样机，先由家长核对适用场地、设备状态及停止方式；儿童使用验收尚未完成。首次体验只使用已核验的行走／泡泡功能，不使用点火或狂暴模式。

1. **家长开机并等待联网。** OLED 待机显示设备地址。语音联网与局域网网页是不同入口：云端对话不可用，不等于网页一定不可用。
2. **手机加入同一可互通网络。** 打开屏幕上的 `http://<设备 IP>:8080/`。访客隔离或手机热点隔离可能阻止访问；不要凭空猜设备地址。
3. **先找到“全部停止”。** 页面底部按钮和本机 BOOT 都用于动作停止。网页当前连接后自动申请会话，不需要注册账号；同一时间只能有一个网页会话。
4. **完成一次短动作。** 家长核对场地与配置后，按住方向键，松开停止；或者试一句“左转一秒”。PWM 不是实测速度，自动避障默认关闭。
5. **一起观察和表达。** 孩子可以提出“先左转，再吹泡泡”的想法；家长决定是否执行。普通语音组合当前会直接请求动作，并没有编排预览确认。预览编排为开发计划，不能以未来功能说明现有行为。
6. **结束时全停。** 关闭页面不会使旧动作在下次连接时恢复。补液、搬动与检修按实物操作说明执行。

ct43 候选将本卡的关键步骤放入网页“第一次使用 · 为什么没动”，并显示真实回执解释；候选尚未部署，现用 ct42 仍按本卡操作。

## 遇到问题

| 看到／听到的情况 | 家长可以做什么 |
|---|---|
| 屏幕没有地址 | 等待配网／联网，核对[已保存网络](wifi-configuration.md)；不要反复发动作 |
| 手机打不开网页 | 核对完整 IP 与 8080 端口、同一网络及客户端隔离；IP 可能在切网后变化 |
| 另一网页正在使用 | 关闭自己先前的遥控页面，等待原会话释放；不刷新抢占 |
| 听到滴声但没有停车 | 提示音与停车开关独立；只有开启前进保护才按距离停前进 |
| 前进被锁定 | 家长检查实际障碍；有效距离至少 20 cm 后解锁，需要新指令，不会续走 |
| 距离显示 `-` | 当前读数无效、过期或未连接；不能据此说前方没有障碍 |
| 动作忙碌或冷却 | 等待该通道实际状态变化后重新明确请求；机器人不会补做失败请求 |
| 断线后重新连接 | 核对状态，再决定新动作；不要期待恢复上一动作 |

首次使用计时从“家长看到开机指引”开始，到“打开网页、完成指定动作并全停”结束。网络准备时间单独记录。目标为 5 个家庭中至少 4 个在约定条件下 3 分钟完成；目前尚无试用结果。
