# 整机验收计划

按 R 编号对照[产品需求](requirements.md)。先记板卡、固件、供电、负载和环境，再分别记录软件回执、仪器量测与实际现象。样机、打印交付和动作分项已有记录，当前整机的持续负载、热状态、机械停止和使用条件仍待验收。[当前状态](current-status.md) · [现场材料](validation/README.md) · [待办](TODO.md)

## 阶段

| 阶段 | 输入与工作 | 退出条件 |
|---|---|---|
| P0 需求与资料 | 需求、官方协议、部件资料、采购记录、冲突清单 | 文件可读、链接有效、部件资料校验记录完整，限制如实记录 |
| P1 实物与功率核对 | Q01–Q06，接口尺寸和额定条件 | 冻结首轮硬件清单，确认电源连续及启动余量、针序和默认关闭 |
| P2 低压台架 | 本地停止、主控与音频、单侧／双侧电机、单个液体效果 | 启停、方向、时限、热状态及电源行为有实测记录 |
| P3 机器人 CAD | 实际包络、满／空液体质量、维护路径 | 三视图符合需求；装配和排液方案明确；保存后检查完成 |
| P4 语音接入 | 台架稳定、账号及板卡可用 | WSS、音频、MCP、拒绝非法指令、断网停止通过 |
| P5 低压整机联调 | 装配完成、阶段测试通过 | 带载、组合效果、噪声、液体、停止和续航证据齐备 |
| PX 底盘前方双火花效果评估 | Q09、专业安全与 EMC 评估 | 明确是否继续采用及适用边界；没有资料不得进入共装通电 |

## 验收矩阵

| 项目 | 对应需求 | 核对内容 | 需要的记录 |
|---|---|---|---|
| V01 | R01、R02 | CAD 保存回读、两履带清点、静态／装配路径检查 | 文件哈希、对象与包络、三视图、碰撞和维护记录 |
| V02 | R02、R03 | 电机、L298N 驱动板、编码器与联轴器确认 | 标签、供电／跳线、针序朝向、尺寸、逐通道转向与手转计数记录 |
| V03 | R08 | 供电与发热 | 端口／升压／L298N／电机端电压电流，逻辑供电及回灌、启动波形，温升与环境条件 |
| V04 | R03、R09 | 默认关闭与停止（已记录分项与装车完整验收分别核对） | 开机、复位、拔插、停止、欠压结果；输出关断延迟与实际滑行距离分别记录 |
| V05 | R04 | 水枪启停 | 额定条件下供能窗口、模块脉冲行为、关断后残液和漏水 |
| V06 | R05、R10 | 泡泡前吹与排液 | 风向、停机滴液、姿态变化、维护及电子仓状态 |
| V07 | R07 | 平台及音频 | 绑定、握手、采样率、工具列表和调用结果，敏感字段脱敏 |
| V08 | R07、R09 | 不良请求与网络故障 | 非法参数、重放、重复、过期、断网、重连与 OTA 后无动作恢复 |
| V09 | R01、R08、R10 | 完整布局 | 低位平放实测电源的端口、底部取出路径；动力外移、底盘加宽与电源前移后的满液／空液稳定性、线束余量、补液与拆洗 |
| V10 | R03–R05、R07–R09 | 带载组合工作 | 电源、热、音频、EMC、液体、停止、地面条件与持续时间 |
| VX | R06 | 底盘前方双火花效果独立评估 | 真实规格及适用边界、专业评估结论；覆盖左右各两根线的拟议效果区域、防触碰及液体共存；未通过前无集成测试 |

## 实施与判定

- V01、V02、V09 从 [VF01 试配](../hardware/model/drive-fit-fixture/README.md)、[当前打印项目](../hardware/model/lean-print/README.md)和[装配指南](assembly.md)核对。记录实际材料、紧固件、拆装次数、承载和满／空液状态。
- V03–V06、V10 使用当前电池与对应负载，分别记录电压、电流、温升、滴液和停机残余。区分软件关断时间、电气输出关断与机械停止距离。[台架分项](validation/bench.md) · [电源预算](../hardware/architecture/README.md) · [停止场景](validation/stop-trials.md)
- V07、V08 分开核对设备联网、平台工具选择、执行回执、断线及恢复。ct45 已有隔离文本评测与设备草稿检查，真人语音、有效确认后的表演和负载故障仍需现场记录。[语音评测](validation/README.md) · [固件测试](../firmware/tests/README.md)
- PX／VX 单独评估。原理图禁用点火装配，低压接口软件计时与物理高压安全验收独立。[A2 设计状态](../hardware/schematic/README.md) · [效果控制](effects-control.md)
