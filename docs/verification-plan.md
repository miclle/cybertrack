# 整机验收计划

按 R 编号对照[产品需求](requirements.md)。先记板卡、固件、供电、负载和环境，再分别记录软件回执、仪器量测与实际现象。样机、打印交付和动作分项已有记录，当前整机的持续负载、热状态、机械停止和使用条件仍待验收。[当前状态](current-status.md) · [现场材料](validation/README.md) · [待办](TODO.md)

## 阶段

| 阶段 | 输入与工作 | 退出条件 |
|---|---|---|
| P0 需求与资料 | 需求、官方协议、部件资料、采购记录、冲突清单 | 文件可读、链接有效、部件资料校验记录完整，限制如实记录 |
| P1 实物与功率核对 | Q01–Q06，接口尺寸和额定条件 | 冻结首轮硬件清单，确认电源连续及启动余量、针序和默认关闭 |
| P2 低压台架 | 本地停止、主控与音频、单侧／双侧电机、单个液体效果 | 启停、方向、时限、热状态及电源行为有实测记录 |
| P3 机器人 CAD | 实际包络、满／空液体质量、维护路径 | 三视图符合需求；装配和排液方案明确；保存后检查完成 |
| P4 语音接入 | 台架稳定、账号及板卡可用 | WSS、音频、MCP、拒绝非法指令、断网停止通过 |
| P5 低压整机联调 | 装配完成、阶段测试通过 | 带载、组合效果、噪声、液体、停止和续航证据齐备 |

## 验收矩阵

| 项目 | 对应需求 | 核对内容 | 需要的记录 |
|---|---|---|---|
| V01 | R01、R02 | CAD 保存回读、两履带清点、静态／装配路径检查 | 文件哈希、对象与包络、三视图、碰撞和维护记录 |
| V02 | R02、R03 | 电机、L298N 驱动板、编码器与联轴器确认 | 标签、供电／跳线、针序朝向、尺寸、逐通道转向与手转计数记录 |
| V03 | R08 | 供电与发热 | 端口／升压／L298N／电机端电压电流，逻辑供电及回灌、启动波形，温升与环境条件 |
| V04 | R03、R09 | 默认关闭与停止（已记录分项与装车完整验收分别核对） | 开机、复位、拔插、停止、欠压结果；输出关断延迟与实际滑行距离分别记录 |
| V05 | R04 | 水枪启停 | 额定条件下供能窗口、模块脉冲行为、关断后残液和漏水 |
| V06 | R05、R10 | 泡泡前吹与排液 | 风向、停机滴液、姿态变化、维护及电子仓状态 |
| V07 | R07 | 平台及音频 | 绑定、握手、采样率、工具列表和调用结果，敏感字段脱敏；普通滴声在监听／播报期间暂缓、结束按实时距离恢复且不补播，紧急停车告警优先；听感和软件回放分列 |
| V08 | R07、R09 | 不良请求与网络故障 | 非法参数、重放、重复、过期、断网、重连与 OTA 后无动作恢复 |
| V09 | R01、R08、R10 | 完整布局 | 电源端口与取出路径、线束余量、双瓶独立取出与补液；分别记录满／空液行走、转弯和急停时的整机稳定性、瓶体窜动、跳出与溅漏 |
| V10 | R03–R05、R07–R09 | 带载组合工作 | 电源、热、音频、EMC、液体、停止、地面条件与持续时间 |
| VX | R06 | v2 点火退役核查 | 检查机械和电气预留移除、旧动作和序列拒绝、GPIO21 未被执行器初始化及全停回归 |

## 实施与判定

- V01、V02、V09 从 [VF01 试配](../hardware/model/drive-fit-fixture/README.md)、[当前打印项目](../hardware/model/lean-print/README.md)和[装配指南](assembly.md)核对。记录实际材料、紧固件、拆装次数、承载和满／空液状态。
- V03–V06、V10 使用当前电池与对应负载，分别记录电压、电流、温升、滴液和停机残余。区分软件关断时间、电气输出关断与机械停止距离。[台架分项](validation/bench.md) · [电源预算](../hardware/architecture/README.md) · [停止场景](validation/stop-trials.md)
- V07、V08 分开核对设备联网、平台工具选择、执行回执、断线及恢复。已有旧版本隔离文本评测；当前候选需复验语音组合、序列、停止与负载故障，旧成绩不迁移。[语音评测](validation/README.md) · [固件测试](../firmware/tests/README.md)

## 产品改进验收

| 编号 | 完成条件与依据 |
|---|---|
| I01、I02 家庭体验与上手 | 五组首次体验中，至少四组在三分钟内独立完成连接、首次动作和停止，至少三组在自由环节主动重复同一玩法。实物、无动作原型和主持人演练分别记录。[观察方法](validation/README.md#家庭体验观察) |
| I03 语音语义 | 固定集工具与参数匹配率 ≥95%，禁止动作误启动为零，明确停止均直接调用。20 条真人口述另报。旧 80／8 集含已退役功能，仅供同版复算。ct79 仍需验证直接动作与拒绝退役请求。[语音验证](validation/README.md#语音工具选择) |
| I04 停止与恢复 | 同配置、同条件至少五次，按控制来源核对关断范围与旧动作不恢复，分开测输出与机械停止。[停止矩阵](validation/stop-trials.md) |
| I05 供电、续航与成本 | 三次同工况典型流程，记录额定条件、电压、电流、温升、中断与复位。采购、打印、报废与工时分别留据。[测量与成本](validation/README.md#电源续航与成本) |
| I06、I07 | 独立表演编辑与模板已取消。直接组合和序列仍按 R09 验收。[退役记录](validation/theatre-removal.md) |
| I08 状态解释 | 依据真实回执说明拒绝原因，缺数据时保留未知，无额外启动或自动重试。[状态解释](status-explanation.md) |
| I09 维护 | 对补液、清洁、取瓶、换电池与检修线束各做至少三次同条件基线，最慢两项分别缩短至少 30%。另记录十次拆装与故障。[记录方法](validation/README.md#维护与修改效率) |
| I10 工程效率 | 核对源码与设备版本，积累五次完整修改的人工、等待、返工和回归记录。[工程日志](validation/engineering-log.md) |
| I11 模型辅助设计 | 在研究副本按目标修改、保存重开、对照其余零件并恢复。0.9.2 的 GUI 和宿主消息验收、迁移至 0.9.3 的复核各有独立记录。[SolidCue 接入](../tools/solidcue/README.md) |
| I12 硬件架构 | H01 电源预算、H02 保护与断电、H03 噪声与回流、H04 接口与检修、H05 部件几何来源、H06 设计参考与采纳依据。定值、装配与带载数据按 V01–V10 实测。[硬件架构](../hardware/architecture/README.md) |
| I13 灵矽参考方案 | 角色、工具、设备回执与硬件接口可追溯，参考包可离线复算历史调用。真实平台、设备与家庭分别验证。[方案](lingxi-solution.md) · [参考包](../tools/lingxi-solution/README.md) |
