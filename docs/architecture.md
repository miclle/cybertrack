```mermaid

  MCU <--> CLOUD[灵矽语音与智能体]
  MCU --> AUDIO[音频输出与扬声器]
```

图中为功能关系，不是电气接线图。顶部双火花效果尚未进入执行器架构；不设置可调用的高压工具或 GPIO。执行器电源切断应独立于云端与 MCU 正常运行，具体器件待负载确定。

日常运行只依赖 ESP32 设备及灵矽平台，不引入 Mac／USB 转发或用户专用云服务。独立音频板基于原小智固件保留音频采集、传输、播放和 OLED，在设备自身会话中新增 CyberTrack 状态／停止工具；源码、GPIO 和实测边界见[音频板记录](audio-board-validation.md)。ct4 已增加本板 GPIO18 五秒水枪输出、BOOT 提前停止和断线关闭，不要求逐次按键授权；不转发到原水枪板。功率断开电压检查与真实喷水结果分开记录，用户确认控制线纠正后测试正常，带载 BOOT 提前停止及松开不恢复也已确认，见[喷水联调](audio-water-validation.md)。网页体验属于另一会话，其跨设备工具路由未通过验证，不能当作已实现入口。

## 模块职责

| 模块 | 职责 | 不承担的职责 |
|---|---|---|
| 语音与平台适配 | 配网、绑定、音频、消息封装、状态提示 | 不决定 GPIO 电平或绕过本地限制 |
| 命令入口 | 验证工具、类型、范围、会话、重复与时效 | 不根据转写文本直接启动电机 |
| 本地动作控制 | 输出互斥／限时、停止优先、拒绝不具备条件的动作 | 不依赖网络定时关断 |
| 行走驱动 | 左右方向与 PWM、编码器计数；后续按实测闭环 | 不承诺未校准的厘米或角度精度 |
| 效果控制 | 经已核实的功率开关控制水枪和泡泡机供能 | 不重新生成模块已有脉冲机构的节拍 |
| 电源与状态 | 复位、欠压／故障处理；可用传感器按硬件确认 | 不凭 USB 电压推算准确剩余电量 |

## 状态与优先级

- `BOOT`：所有动作禁止，硬件默认关闭；自检完成进入 `DISARMED`。
- `DISARMED`：可联网与交流，拒绝执行器动作；本地明确使能后进入 `READY`。
- `READY`：接收合法短时命令；执行时进入 `ACTIVE`，到时回到 `READY`。
- `FAULT`：停止、欠压、控制异常或活动中的会话丢失均撤销输出并锁定。恢复条件满足后仍需本地重新使能。

优先级为：物理断电／停止 > 故障与时限 > 正常动作。掉电、重连和 OTA 结束不重放动作队列。TTS 播报“已停止”不等于已经停止，必须先撤销输出。

F2a [运行层](../firmware/RUNTIME.md)已实现启动先关断、周期输入采样、输出调用及失败锁定、条件喂狗。运行层故障关闭协议会话并抑制本轮响应；普通停止解除后仍需新的本地使能按键边沿。通用输入去抖、已观察短脉冲锁存及有界接收队列已通过主机测试；真实电平映射、中断捕获、跨任务交接、调度及硬件看门狗尚待 F2b。

已完成[接收边界与连接流程模拟](../firmware/TRANSPORT.md)：两层分片、首次接收元数据保持、阶段超时、旧连接事件隔离和发送失败关闭。网络事件只登记断线，周期控制服务优先应用；传输工作线程持有按连接代次绑定的响应副本，不阻塞本地控制。该通用运行层的真实板级交接仍待集成；独立状态／停止工程已接入 ESP-IDF、TLS／hello 和有界接收队列，正式核心动作能力固定关闭；0.2.0 的水枪台架通道单独维护本机一次性授权，见[实测记录](linx-validation.md)。

网络停顿有两层限制：已知断开立即取消，尚未检测到断开时由本地动作时限兜底。应用存活检测的具体阈值待接入联调，不允许无期限持续行驶。

## 并发策略

首轮台架逐个测试行走、水枪、泡泡。组合动作属于后续验收项：只有完成供电、EMC、滴液和停止验证后才启用；不能根据单模块成功推导整机同时运行成功。音频与 Wi-Fi 在每轮负载测试中保持运行，记录语音丢帧及 MCU 复位。

## 固件边界

当前台架与联网工程采用 ESP-IDF v5.5.1；主控已指定 ESP32-S3 N16R8，[COREBOARD 原理图和排针](../hardware/components/ESP32-S3-N16R8/README.md)已整理，实物修订版、焊装与项目 GPIO 分配待核对。SDK 稳定版本、Flash／PSRAM 实物配置、麦克风、功放及音频编码依赖在相应资料补齐后锁定。当前 C11 核心与协议层可在主机及独立 ESP32 工程编译，输出仍为逻辑目标；0.1.0 联网工程沿用已核对台架 GPIO4 仅拉低；0.2.0 新增独立单次授权水枪策略及控制任务，GPIO4 仅在该意图通过时限、BOOT 和连接检查后供能，未冻结整机 GPIO 表。F1 已加入 16 槽 FIFO 原响应、跨连接保留的启动期防重放过滤器和本地使能代次检查；淘汰／重连不恢复旧动作，过滤器碰撞保守拒绝。跨复位记录恢复已通过双槽存储与假板卡模拟，真实 Flash／NVS 尚未接入；设备限时窗口和独立稳定意图 ID 已通过离线模拟；真实传输必须提供经过认证并绑定动作内容的命令新鲜度证据，不能只凭刚收到消息开放动作。按[固件独立计划](../firmware/PLAN.md)继续验证板级停止与默认关闭，最后开放已通过台架的动作能力。
