# 效果控制与停止

水枪和泡泡分别由独立的低压 MOS 支路控制。固件还提供共用双线圈的低压接口。A2 原理图保持 JP2 断开、U10／J9 不装配，高压接线、绝缘、液体共存和 EMC 尚未验收。亲子上手与剧场编排使用行走和泡泡。[A2 设计](../hardware/schematic/README.md) · [现行能力手册](../firmware/CAPABILITIES.md)

## 通道与引脚

| 动作 | 源码控制引脚 | 语音默认／最大单次 | 停止后操作间隔 | 功率侧证据与缺口 |
|---|---|---|---|---|
| 行走 | GPIO8–13；B／左、A／右，60–100% PWM | 全速左右转默认 880 ms，其余默认 1 秒；定时最多 2147483647 ms，网页长按另用租期 | 200 ms | ct21 四方向获用户正常反馈；定量速度、停止距离、电流／温升未验收 |
| 水枪 | GPIO18 | 1 秒／30 秒；网页支持长按 | 200 ms | MOS→降压至 3.7 V 支路已有短时喷水及 ct7 并发分项记录；当前电源与完整负载仍待验证 |
| 泡泡枪 | GPIO17，独立一块 P01 | 1 秒／30 秒；网页支持长按 | 200 ms | 用户确认工作电压 3.7 V，已有样机出泡影像；逐线核对、降压／MOS 适配及完整电气验收仍待完成 |
| 两只点火线圈 | GPIO21，共用一块 P01、同时启停 | 1 秒／5 秒；无长按持续接口 | 至少等本次实际软件 ON 时长 | 用户指定 5 V；两只总电流、启动瞬态、开关适配与高压验收尚未完成 |

GPIO17／21 在固定版本 `bread-compact-wifi/config.h` 的音频、显示、按钮分配及原电机／水枪驱动中未占用，低压控制源码已部署。实际引出脚、排针和完整布线尚未独立逐线核对，不能从其他型号开发板推定针位。软件初始化先写低再配置输出；启动之前、复位期间真实电平和 MOS 悬空关断仍须独立验证。影像中的出泡不证明 GPIO、电源或版本配置全部核实。

三块 P01 分别用于水枪、泡泡和两只点火线圈；“双 MOS”是一路并联开关，并非两个独立通道。原水枪短时成功不证明新负载适配。等长点火间隔不是热保护或厂家允许占空比；软件时长包含调度误差，无电气通电时长反馈。泡泡三十秒及长按能力也不代表持续运行验收。

## 四路独立与统一停止

- 普通定时动作四路可同时运行，每一路有独立截止、间隔和来源；启动／结束泡泡或点火不重启其他输出。
- 普通同路定时请求不续时、不叠加、不排队；到期不自动循环。网页行走／喷水／泡泡长按通过有效租约维持，松开只停本路；语音不提供长按续租，点火不提供持续接口。
- 狂暴模式须四路均就绪，总时长 1–30000 ms：左转、喷水、泡泡持续，点火每次最多 1000 ms，关闭后至少等实际软件 ON 时长再启动下一脉冲。末尾脉冲不越过模式总截止，重复请求不续期；该明确模式是有界循环，普通动作不自动升级为模式。
- BOOT、语音停止、网页全部停止、Wi-Fi 断开、重启／OTA 入口、输出故障及时钟异常关闭全部通道并取消待执行请求；释放按键和恢复网络不恢复旧动作。GPIO API 失败锁定故障并尽力关断，不保证故障器件的物理断开。
- 网页可抢占同路普通语音动作，但先停止并等待本路间隔，需再次手动发起；语音不能覆盖同路网页动作。网页普通动作抢占语音狂暴模式时取消整个模式并返回 `voice_preempted`，不部分保留或自动启动；网页狂暴请求须四路就绪。
- 网页离开／心跳失效只停止网页来源动作；语音会话断开只停止语音来源动作，模式按来源取消。行走长按失租撤销所有网页来源动作；喷水／泡泡失租只停本路。全局停止覆盖所有来源。

## 接口与角色

MCP `self.tank.bubbles({"duration_ms":1000})` 接受整数 1–30000，`self.tank.ignition({"duration_ms":1000})` 接受整数 1–5000；仅允许 `duration_ms`，拒绝缺参、多参、重复键、注入票据、非整数及越界。角色在明确普通动作但缺少时长时填 1000 ms，超限只请求对应上限并说明，不分段；固件不自行补参或截断。

`self.tank.frenzy({"duration_ms":5000})` 接受整数 1–30000，角色默认 5000 ms；与网页使用同一有界模式。`move_and_water` 仍是行走／喷水两路原子组合；其他分别发出的普通动作不保证全部接受，狂暴模式须四路就绪后整体启动。

HTTP `/api/action` 的 `bubbles/ignition/frenzy` 使用 `operation/sequence/window/duration_ms`，范围同上；喷水／泡泡另有 `start/renew/stop` 长按接口。网页喷水／泡泡各有 1／3／5／10／30 秒及按住持续，点火有 1／3／5 秒，狂暴模式有 5／10／30 秒。租约、来源与全部请求字段见[局域网控制](lan-control.md#http-契约)。

状态包括 `logical_outputs.water/bubbles/ignition` 及各路计时、间隔和来源；能力包含 `bubbles/ignition/water_hold/bubbles_hold/frenzy`。`remaining_ms` 为四路最大剩余值，模式另读 `frenzy_remaining_ms/frenzy_last_duration_ms/frenzy_source`，不按点火 ON/OFF 判断模式结束。`starts_this_boot` 是软件启动计数，后端为 `concurrent_motor_effects_bench`，`physical_feedback=false`；回执不代表出泡、火花或实体停止反馈。完整字段见[当前接口手册](../firmware/CAPABILITIES.md#当前面包板-ct21-接口)。

[角色源](../firmware/esp32-audio/role-prompt.txt)按[角色同步流程](agent-role.md)维护；当前角色的工具选择和回复结果见[隔离评测](validation/lingxi-ct45-role-feedback-20261031.md)。仅明确点火／火花或明确狂暴模式请求可选择相应工具，不从其他普通动作或含糊效果请求推断点火；状态、否定句和背景谈话不启动动作。角色默认值和话术不能代替固件限制。
