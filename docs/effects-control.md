# 喷水与泡泡控制

CyberTrack v2 的 MOS 支路只用于喷水和泡泡。枪体内各自保留 3.7 V 降压板。固件独立控制两路，网页还支持长按。点火和带点火的狂暴模式已从 v2 退役。

工程样板 A1 在主板上分别切换两支枪的 5 V 正极，枪内 P12 提供 3.7 V。另有一路 GPIO14 控制的预留 5 V 输出，当前网页和语音接口只操作两支枪。下表给出模块样机的开关与固件时序。[A1 插座与限流设置](../hardware/pcb/README.md)

| 功能 | 固件输出 | 定时窗口 |
|---|---|---|
| 喷水 | GPIO18，经独立 JZ-MOS | 1–30000 ms |
| 泡泡 | GPIO17，经独立 JZ-MOS | 1–30000 ms |

两路可以与行走并发；每路独立截止，停止后至少间隔 200 ms。同路定时请求不续时或排队。网页长按由短期租约维持，松开停止本路。BOOT 和全部停止停止所有执行器并取消剩余步骤，故障或 Wi-Fi 断开后恢复需新指令。[网页与语音接口](lan-control.md) · [动作序列](action-sequences.md)

旧网页点火和狂暴模式请求返回 `unsupported_operation`，旧语音工具停止注册。任何含旧 `ignition_ms` 字段的序列整单拒绝。明确的全停与查询仍可用。历史记录可从 Git 的 v1 版本查阅。

逻辑回执记录输出请求，不包含水流或出泡反馈。实际启动电流、供液、余液、滴漏、液体与电控隔离以及停止表现仍按样机分项核验。[接线总表](wiring.md) · [物料清单](../hardware/BOM.md)
