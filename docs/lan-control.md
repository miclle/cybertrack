# 局域网网页与语音控制

ct42 补充：距离滴声不受开关或行走状态影响，待机／后退／转向也按有效距离提示；开关只控制停车。见[距离提示音规则](ultrasonic-ranging.md#ct42距离提示音独立于开关与行走)。

## 上手帮助与回执解释

页面的“第一次使用 · 为什么没动”提供亲子上手步骤、当前状态和最近请求的只读解释；不会发起动作。过期、缺失或未知数据明确说明无法判断，详见[解释规则](status-explanation.md)。帮助入口由 ct43 引入，已随 ct45 部署；同版网页还提供可预览、需明确确认的[泡泡剧场](show-composer.md)。

## 自动避障开关（ct41 已部署）

在速度滑块下方点击“自动避障”，以设备回执更新开启／关闭状态，未连接或旧固件缺少状态字段时不可操作。开机默认关闭；开启后小于 15 cm 停止前进，达到 20 cm 解锁但需新指令。设置同时作用于网页和语音，刷新／重连保持，设备重启恢复关闭；关闭不会恢复旧动作。距离提示音按有效读数播放。接口、阈值及有效读数规则见[说明](ultrasonic-ranging.md#ct41自动避障开关已部署)。已部署并完成网页开关两态检查，最终恢复关闭，见[部署记录](../firmware/esp32-audio/startup-ct41.json)。


## 屏幕上的内网地址（ct40）

128×32 OLED 在待机时用全宽底行显示当前 `IPv4:8080`，例如 `192.168.1.123:8080`；示例不是设备当前地址。手机连接同一可互通的局域网后，在浏览器输入 `http://` 加屏幕上的地址。端口仍为 `8080`，不是 HTTPS。

地址独立于聊天文字保存。待机时临时隐藏大表情，为完整地址留出一行；出现对话／系统文字时恢复原表情和滚动字幕，回到待机后恢复地址。Wi-Fi 断开或丢失 IP 后，待机显示 `Wi-Fi offline`，不保留旧地址；重新联网后使用新地址。状态栏和临时通知不覆盖地址行。

设备断网时显示离线，重新联网后使用新的地址。手机访问与地址显示已有[现场反馈](../firmware/esp32-audio/startup-ct40.json)。

## 操作

- 手机和设备在同一可互通局域网，打开 `http://<设备 IP>:8080/`。地址通过 OLED 和串口 `CT_WEB` 显示；没有 PIN、账号或接管按钮。仅一网页会话同时连接，其他页面每 1.5 秒重试连接，不抢占。
- 按住方向键持续行走，松开停止行走。页面从按下时用单调时钟计算经过时间，每 0.1 秒显示“已按住 X.X 秒”；松开、取消、全停、后台或失联时冻结为“本次按住 X.X 秒”，下一次按下从零开始。此数值是浏览器按住时长，含请求准备／网络等待，不是实际输出时长或机械行走时间。触屏、鼠标及空格／Enter 均支持；滑出、触控取消、失去捕获或焦点均停止。不同方向不同时执行，换向先松开，行走停止后间隔 200 ms。
- 喷水和泡泡各有 1／3／5／10／30 秒及“按住持续”六个按钮；可与行走多指同时按住，松开仅停对应一路。定时与其他通道独立计时，没有组合开关；两路停止后各间隔 200 ms。
- 点火有 1／3／5 秒三个按钮，无长按持续入口；一路低压 MOS 同时控制两只模块，停止后至少间隔本次实际软件 ON 时长。逻辑接受不代表实际火花或硬件验收，见[效果控制](effects-control.md)。
- 狂暴模式提供 5／10／30 秒，四路均就绪后整体启动，持续左转、喷水、泡泡，点火每次最多一秒并有等长关闭间隔；总时长不续期。运行中其他启动按钮禁用，全部停止始终可用。
- “全部停止”、BOOT、语音停止均结束四路及狂暴模式，停止不会关闭音频或屏幕。
- 页面后台／关闭、长按／模式运行或动作请求在途时窗口失焦、网页心跳失效会停止**网页发起的动作**；其他通道上的独立语音动作保留自己的截止时间。返回前台或恢复网络会自动重新连接，只恢复状态，旧动作不重放、不自动恢复。
- Wi-Fi 断开、重启／OTA、输出故障和时钟异常关闭四路及狂暴模式。云端语音通道关闭只停止语音来源的动作，不打断网页动作。

页面显示连接、四路实时状态、方向键、喷水／泡泡／点火按钮、狂暴模式及全部停止。动作成功提示随设备状态更新，全部结束时显示“动作已结束。”；不是浏览器倒计时证明实物停止。所有状态来自固件逻辑，无轮速、水流或火花传感反馈。手机可以连接桥接到同一局域网的 5 GHz Wi-Fi；访客隔离／客户端隔离会阻止访问。

ct52 候选网页在动作进行中或停止回执未确认时失联，会持续提示家长可用设备 BOOT 键立即全停。重新配对后仍保留提示，直至读到新鲜、无故障的设备状态。若独立的语音泡泡仍在运行，网页会显示该活动。板上版本见[当前状态](current-status.md)。

## 网页优先与语音并用

连接页面本身不停止动作、不取消语音队列，也不阻止新的语音命令。固件分别记录四路活动与模式的来源。网页与语音可以控制不同通道；同通道不续时、不叠加。

| 场景 | 行为 |
|---|---|
| 网页已连接但空闲，收到语音动作 | 按原时限和冷却执行 |
| 网页行走，语音喷水；或网页喷水，语音行走 | 另一通道空闲且不在冷却时执行 |
| 语音请求覆盖活动中的同通道网页动作 | 拒绝，不排队、不重试、不打断网页 |
| 合法普通网页请求遇同通道正在执行的语音动作 | 立即停止该语音动作，返回 `voice_preempted`；保留冷却，用户需冷却后重新按下／点击，不自动启动 |
| 普通网页请求与同通道尚在应用队列中的语音请求冲突 | 取消相应语音票据；另一通道的独立票据保留 |
| 关闭网页，另一通道仍有语音动作 | 仅停止网页动作，语音动作按时截止 |
| 网页普通动作遇语音狂暴模式 | 取消整个语音模式，返回 `voice_preempted`，保留间隔；不部分继续或自动启动新动作 |
| 全部停止／BOOT／Wi-Fi 断开 | 四路及模式停止，旧请求不能恢复 |

网页优先不绕过行走／喷水／泡泡各 200 ms、点火等实际软件 ON 时长的间隔，以及 BOOT 或故障条件；不是无间隔换向。语音 `move` 为 1–2147483647 整数毫秒，`water/bubbles` 最多三十秒，`ignition` 最多五秒；`move_and_water` 要求两路均就绪，`frenzy` 要求四路均就绪、最多三十秒。模式活动期间不接受其他语音启动或续时；网页狂暴请求也须四路就绪，不会排队等待。

## 时序与实现约束

- 原优先级 10、5 ms 控制任务检查截止；HTTP、语音和 BOOT 共享带优先级继承的互斥锁，驱动先应用再返回回执。活动截止任务不进行网络、显示、日志格式化或堆分配。
- 网页连接心跳 2000 ms；行走／喷水／泡泡长按各使用 600 ms 租期，收到上次回执后约 150 ms 续租。续租串行且使用一次性 `renewal`，不重复初始化 PWM 或重复启动；状态轮询本身不能维持任何长按。行走短租期失效撤销所有网页来源动作；喷水／泡泡短租期失效仅停本路，独立语音通道仍保留自己的截止。
- 网页确认的多步表演依赖网页会话。页面释放请求送达后立即取消；网络静默中断时，当前租期内还可能进入下一步。租期届满后取消，重新连接不会补做。[两种断线的回放对照](validation/stop-trials.md#已部署版与候选版的固件主机回放)
- 常态每次状态响应后约 500 ms 轮询，冷却期间按剩余间隔提前查询。开始长按前额外获取最新窗口，避免 500 ms 轮询加网络延迟造成开始窗口过期；等待窗口时松开不会补发启动。
- 网页独立通道请求可与其他长按续租并行，但不重放动作。自动连接只获取会话和状态，没有缓存动作队列。
- 窗口只消费一次，普通动作窗口小于 1500 ms、长按开始窗口小于 600 ms；动作序号严格递增。停止使旧窗口失效；松开可以先于启动到达并留下取消标记，晚到的启动／续租不能恢复。
- 电机使用 1 kHz、60–100% PWM（默认 100%），状态逻辑输出为有符号百分比；长按使用独立租约，喷水／泡泡长按也可超过三十秒定时上限；持续带载、温升及机械停车距离尚未验收。600 ms 是软件策略，不能当成实测机械停止时延。

## HTTP 契约

页面及所有资源内嵌应用，8080 与原配网服务分开；无 CDN、mDNS 或独立服务器。API 使用 POST、`Content-Type: application/json` 和 `X-CyberTrack-Client: 1`；除 `/api/pair` 外需要 `X-CyberTrack-Token`。只接受当前 STA IPv4 的 Host，提供 Origin 时必须同源，无 CORS 放行。

| 路径 | 请求 | 用途 |
|---|---|---|
| `GET /` | 无 | 控制页面 |
| `/api/pair` | `{}` | 保留路由名，自动建立单网页会话，不要求 PIN、不抢占其他页面、不停止语音 |
| `/api/state` | `{}` | 续网页心跳，签发动作窗口并返回状态 |
| `/api/action` | 下表 | 发起动作／续租／松开 |
| `/api/stop` | `{}` | 停止四路及模式、作废旧窗口，保留连接 |
| `/api/release` | `{}` | 页面生命周期内部调用，停止网页来源动作并撤销会话；UI 无手动释放按钮 |

开始类操作须带非零 uint32 `sequence`、`window`：

| operation | 额外字段 |
|---|---|
| `set_speed` | `speed_percent`，60–100 的整数 |
| `set_auto_avoidance` | `enabled`，布尔值 |
| `show_edit`／`show_confirm` | 编辑传 `draft`，确认传预览的 `revision`，见[编排契约](show-composer.md) |
| `drive_start` | `direction` 为 forward/backward/left/right；保留可选 `water_duration_ms` 供已有接口，当前网页不发送组合请求 |
| `water`／`bubbles` | 整数 `duration_ms`，1–30000 |
| `ignition` | 整数 `duration_ms`，1–5000 |
| `frenzy` | 整数 `duration_ms`，1–30000；四路就绪才整体启动 |
| `water_start`／`bubbles_start` | 无额外字段，使用 600 ms 内的开始窗口 |
| `move` | `direction`、整数 `duration_ms`，1–2147483647；兼容接口，网页使用长按 |
| `move_and_water` | `direction`、`move_duration_ms` 1–2147483647、`water_duration_ms` 1–30000；兼容原子组合接口 |

`drive_renew`、`water_renew`、`bubbles_renew` 只带 `operation/hold_id/renewal`；对应的 `drive_stop`、`water_stop`、`bubbles_stop` 只带 `operation/hold_id`，均不带窗口。`hold_id/renewal` 为非零 uint32；续租必须使用上次回执的凭据，不能重放。正常开始 `result=accepted`，续租 `renewed`，停止／状态 `ok`。`voice_preempted` 表示语音已被停止但**网页新动作尚未启动**；不得当作 accepted。

`/api/action` 请求体上限为 8192 字节，其他 JSON 接口上限为 384 字节。额外／缺失／重复字段、非整数与越界拒绝，socket 收发超时一秒、最多两个连接、8192 bytes HTTP 栈。HTTP 400 参数错误、401 会话失效、403 来源不符、409 网页会话忙、429 接管限流；HTTP 200 仍须核对内部 result。

状态包含 `move_source`、`water_source`、`bubbles_source`、`ignition_source` 及 `frenzy_source`，值为 web/voice/none。`control_owner=shared` 表示网页会话与语音通道同时在线，web/voice/none 表示入口连接情况，**不再表示语音被网页独占禁止**。`drive_hold_id`、`water_hold_id`、`bubbles_hold_id` 非零时，对应 `_remaining_ms` 为短租期剩余，不能作为总运行剩余时长；`drive_lease_ms/effect_lease_ms=600`。模式单独读取 `frenzy_remaining_ms/frenzy_last_duration_ms/frenzy_max_duration_ms`，不能按点火间歇判断结束。`remaining_ms` 为四路剩余值的最大值；各路间隔、能力、窗口、BOOT 和丢日志字段见[接口手册](../firmware/CAPABILITIES.md#当前面包板-ct21-接口)，`physical_feedback=false`。

开发阶段按用户要求无身份认证：同局域网能访问设备的客户端可以申请会话。内存令牌用于会话关联与防止旧请求串入，不作为用户身份认证；不写 URL、cookie 或 localStorage。

编排接口与版本确认见[泡泡剧场](show-composer.md)，状态回执字段见[状态解释](status-explanation.md)。网页检查与设备部署见[当前状态](current-status.md)。
