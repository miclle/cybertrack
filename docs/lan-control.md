# ct12 局域网网页与语音控制

ct12 将行走和喷水操作间隔统一为 200 ms；ct11 增加网页长按计时；ct10 按用户要求移除手动接管／释放、组合喷水开关与冗余说明。网页打开后自动连接，行走和喷水独立，网页与语音可同时使用，同通道冲突时网页优先。ct9 的历史软件／部署证据保存在 [ct9 记录](lan-control-ct9.md)，不直接作为 ct10 验收。

## 操作

- 手机和设备在同一可互通局域网，打开 `http://<设备 IP>:8080/`。地址通过 OLED 和串口 `CT_WEB` 显示；没有 PIN、账号或接管按钮。仅一网页会话同时连接，其他页面每 1.5 秒重试连接，不抢占。
- 按住方向键持续行走，松开停止行走。页面从按下时用单调时钟计算经过时间，每 0.1 秒显示“已按住 X.X 秒”；松开、取消、全停、后台或失联时冻结为“本次按住 X.X 秒”，下一次按下从零开始。此数值是浏览器按住时长，含请求准备／网络等待，不是实际输出时长或机械行走时间。触屏、鼠标及空格／Enter 均支持；滑出、触控取消、失去捕获或焦点均停止。不同方向不同时执行，换向先松开，行走停止后间隔 200 ms。
- 喷水选择 1／3／5／10／30 秒并单独点击。喷水时可以行走，按住行走时可以用另一手指点击喷水；两路独立计时，没有组合开关。松开方向键不停止喷水。喷水结束后间隔 200 ms。
- “全部停止”、BOOT、语音停止均结束两路，停止不会关闭音频或屏幕。
- 页面后台／关闭、行走时窗口失焦、网页心跳失效会停止**网页发起的动作**；其他通道上的独立语音动作保留自己的截止时间。返回前台或恢复网络会自动重新连接，只恢复状态，旧动作不重放、不自动恢复。
- Wi-Fi 断开、重启／OTA、输出故障和时钟异常仍按原规则关闭两路。云端语音通道关闭只停止语音来源的动作，不打断网页动作。

页面只显示连接状态、两路实时状态、四个方向键、喷水时长／按钮和全部停止。所有状态来自固件逻辑，无轮速或水流传感反馈。手机可以连接桥接到同一局域网的 5 GHz Wi-Fi；访客隔离／客户端隔离会阻止访问。

## 网页优先与语音并用

连接页面本身不停止动作、不取消语音队列，也不阻止新的语音命令。固件分别记录活动行走和喷水的来源。网页与语音可以控制不同通道；同通道不续时、不叠加。

| 场景 | 行为 |
|---|---|
| 网页已连接但空闲，收到语音动作 | 按原时限和冷却执行 |
| 网页行走，语音喷水；或网页喷水，语音行走 | 另一通道空闲且不在冷却时执行 |
| 语音请求覆盖活动中的同通道网页动作 | 拒绝，不排队、不重试、不打断网页 |
| 合法网页请求遇同通道正在执行的语音动作 | 立即停止该语音动作，返回 `voice_preempted`；保留冷却，用户需冷却后重新按下／点击，不自动启动 |
| 网页请求与同通道尚在应用队列中的语音请求冲突 | 取消相应语音票据；另一通道的独立票据保留 |
| 关闭网页，另一通道仍有语音动作 | 仅停止网页动作，语音动作按时截止 |
| 全部停止／BOOT／Wi-Fi 断开 | 两路都停止，旧请求不能恢复 |

网页优先不绕过两路各 200 ms 的操作间隔、BOOT 或故障条件；不是无间隔换向。原语音 `move` 最多三秒，`water` 最多三十秒；语音组合工具仍作为一条明确“边走边喷”的指令保留，并要求两路都就绪。

## 时序与实现约束

- 原优先级 10、5 ms 控制任务检查截止；HTTP、语音和 BOOT 共享带优先级继承的互斥锁，驱动先应用再返回回执。活动截止任务不进行网络、显示、日志格式化或堆分配。
- 网页连接心跳 2000 ms；长按行走单独使用 600 ms 租期，收到上次回执后约 150 ms 续租。续租串行且使用一次性 `renewal`，不重复初始化 PWM、不重复启动、不续喷；状态轮询本身不能续走。行走短租期失效停止网页来源通道，语音独立通道仍保留自己的截止。
- 未长按时每次状态响应后 500 ms 轮询。按下方向键前额外获取最新窗口，避免 500 ms 轮询加网络延迟造成开始窗口过期；等待窗口时松开不会补发启动。
- 网页水枪请求在长按时可与续租并行，但不重放动作。自动连接只获取会话和状态，没有缓存动作队列。
- 窗口只消费一次，普通动作窗口小于 1500 ms、长按开始窗口小于 600 ms；动作序号严格递增。停止使旧窗口失效；松开可以先于启动到达并留下取消标记，晚到的启动／续租不能恢复。
- 约 60% PWM 保持，长按允许超过原语音三秒限制；持续带载、温升及机械停车距离尚未验收。600 ms 是软件策略，不能当成实测机械停止时延。

## HTTP 契约

页面及所有资源内嵌应用，8080 与原配网服务分开；无 CDN、mDNS 或独立服务器。API 使用 POST、`Content-Type: application/json` 和 `X-CyberTrack-Client: 1`；除 `/api/pair` 外需要 `X-CyberTrack-Token`。只接受当前 STA IPv4 的 Host，提供 Origin 时必须同源，无 CORS 放行。

| 路径 | 请求 | 用途 |
|---|---|---|
| `GET /` | 无 | 控制页面 |
| `/api/pair` | `{}` | 保留路由名，自动建立单网页会话，不要求 PIN、不抢占其他页面、不停止语音 |
| `/api/state` | `{}` | 续网页心跳，签发动作窗口并返回状态 |
| `/api/action` | 下表 | 发起动作／续租／松开 |
| `/api/stop` | `{}` | 无条件停止两路、作废旧窗口，保留连接 |
| `/api/release` | `{}` | 页面生命周期内部调用，停止网页来源动作并撤销会话；UI 无手动释放按钮 |

开始类操作须带非零 uint32 `sequence`、`window`：

| operation | 额外字段 |
|---|---|
| `drive_start` | `direction` 为 forward/backward/left/right；保留可选 `water_duration_ms` 供已有接口，当前网页不发送组合请求 |
| `water` | 整数 `duration_ms`，1–30000 |
| `move` | `direction`、整数 `duration_ms`，1–3000；兼容接口，网页使用长按 |
| `move_and_water` | `direction`、`move_duration_ms` 1–3000、`water_duration_ms` 1–30000；兼容原子组合接口 |

`drive_renew` 只带 `operation/hold_id/renewal`；`drive_stop` 只带 `operation/hold_id`，均不带窗口。正常开始 `result=accepted`，续租 `renewed`，停止／状态 `ok`。`voice_preempted` 表示语音已被停止但**网页新动作尚未启动**；不得当作 accepted。

保留原参数严格校验：最多 384 bytes，额外／缺失／重复字段、非整数与越界拒绝，socket 收发超时一秒、最多两个连接、8192 bytes HTTP 栈。HTTP 400 参数错误、401 会话失效、403 来源不符、409 网页会话忙、429 接管限流；HTTP 200 仍须核对内部 result。

状态新增 `move_source`、`water_source`，值为 web/voice/none。`control_owner=shared` 表示网页会话与语音通道同时在线，web/voice/none 表示入口连接情况，**不再表示语音被网页独占禁止**。`drive_hold_id` 非零时 `move_remaining_ms` 为短租期剩余，不能作为总行走剩余时长。其余 starts、剩余时间、冷却、窗口、BOOT、丢日志数量和物理反馈字段沿用原格式。

开发阶段按用户要求无身份认证：同局域网能访问设备的客户端可以申请会话。内存令牌用于会话关联与防止旧请求串入，不作为用户身份认证；不写 URL、cookie 或 localStorage。

## ct12 操作间隔

200 ms 是开发阶段的操作间隔，不是温度保护，也不代表零间隔换向已通过带载验证。主机测试覆盖 199 ms 拒绝／200 ms 放行与各停止路径；当前构建目录为 `build/xiaozhi-ct12-src`、`build/firmware-ct12`，部署见 [ct12 记录](../firmware/esp32-audio/startup-ct12.json)。

## ct14 喷水／泡泡六按钮与长按

喷水和吹泡泡各为两行三列：1／3／5／10／30 秒及“按住持续”，替代两路下拉选择。定时仍到期关闭；长按持续、松开仅停止对应一路，多指可同时按住行走、喷水和泡泡。按住时显示已按住秒数，松开保留本次秒数；滑出、指针取消、键盘失焦、窗口失焦、后台和离线取消长按，不自动恢复。切换多指触摸焦点不等于松开。

HTTP 新增 `water_start/renew/stop`、`bubbles_start/renew/stop`：start 字段为 `operation/sequence/window`，renew 为 `operation/hold_id/renewal`，stop 为 `operation/hold_id`。start 使用 600 ms 内的单次窗口；每次有效 renew 消费对应回执序号，将本路截止推进 600 ms，普通状态心跳不续租。松开先于开始到达也能取消旧开始；旧停止不能停止新 hold。每路租期失效只停本路，会话释放及 BOOT／全部停止撤销所有相关 hold。原行走失租的网页来源全停规则保留。

回执新增 `capabilities.water_hold/bubbles_hold`、`water_hold_id/water_renewal`、`bubbles_hold_id/bubbles_renewal`、`effect_lease_ms=600`。ID 非零时剩余时间是租期，不能读成总运行时长。语音只允许定时，不开放续租；泡泡范围变为 1–30000 ms，点火保持 1–5000 ms／间隔 3000 ms。连续负载、电流、温升和实体关断仍需另验。

## ct17 狂暴模式

新增“狂暴模式”标题和 5／10／30 秒三个按钮，显示模式剩余时间。`/api/action` 接受 `operation=frenzy`、`sequence`、`window`、整数 `duration_ms`（1–30000），严格拒绝缺参、额外／重复字段和越界。回执新增 `capabilities.frenzy`、`frenzy_remaining_ms`、`frenzy_max_duration_ms=30000` 和 `ignition_cooldown_policy=equal_elapsed_on_time`。无对应能力时按钮禁用。

固件在同一锁内检查四路均空闲且间隔结束后启动。持续左转、喷水、泡泡与间歇点火共同受固定总截止控制；点火每次最多 1000 ms，关闭后至少间隔实际软件 ON 时长，末尾脉冲不越过模式截止。重复或同通道请求不续时、不排队；点火关闭间隔内仍保留模式对该通道的占用。模式期间禁用其他启动按钮，全部停止与语音停止始终可用。模式结束后恢复普通独立操作。

会话保持现有 2000 ms 心跳失效规则，网页正常每约 500 ms 查询状态；状态只能维持会话，不能延长模式总时长。后台、失焦、关闭、离线会释放；Wi-Fi、BOOT、输出故障、时钟倒退或会话失效取消整个模式，重新连接不恢复。较矮手机视口（≤700 px）将方向键排成一行、缩减提示区，保留 44 px 触控目标和全停间距；较小视口及大字号仍允许自然滚动。

软件及布局证据见 [ct17 验证记录](../firmware/esp32-audio/verification-ct17.json)。模拟测试不代表电机带载、出水、出泡、火花、绝缘、EMC、温升或真实停止时延验收。

ct17 已仅应用刷写并保留配置；启动／联网、实际页面全文一致、能力字段、手机视口及最终全关／释放均已核对。本轮实机 `starts_this_boot=0`，未触发狂暴或点火，动作时序证据来自主机测试。见[部署记录](../firmware/esp32-audio/startup-ct17.json)。

## ct18 语音启动

`self.tank.frenzy({duration_ms})` 允许语音启动同一模式；默认 5000 ms，上限 30000 ms，严格参数校验与内部防重放票据沿用单项语音动作。回执增加 `frenzy_source=web/voice/none` 和 `frenzy_last_duration_ms`；网页仍按 `frenzy_remaining_ms` 显示剩余时间，不从当前点火 ON/OFF 判断模式是否结束。网页模式依赖网页会话，语音模式依赖语音连接；关闭另一来源不误停，Wi-Fi／BOOT／全部停止／故障始终结束模式。网页动作抢占语音模式时取消整个模式并返回冷却拒绝，不部分保留或自动继续。

ct18 已仅应用烧录、保留配置，并在角色保存后重启联网。启动日志含 frenzy 工具，实机状态包含模式来源／时长字段，页面与源码一致，最终全关并释放，动作启动次数为 0。尚未进行真人口述或带载测试。见[部署记录](../firmware/esp32-audio/startup-ct18.json)。
