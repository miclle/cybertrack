# 0.41 超声波与面包板共存候选

2026-10-25。按用户要求将向上出线和托盘前缘让位合入主总装及图纸。头壳、前脸孔位、冠盖和四个托盘固定点保持；未实测部分继续标注为候选。独立U01研究副本已由本页、正式生成脚本和主模型专项报告替代。

本页保留0.41头部结构记录；0.43主总装保持这些头部几何，底盘增加板卡防脱压框与局部接线空间，见[当前结构](effects-mount.md)与[范围审计](../hardware/model/effect-board-change-audit.json)。

## 安装基准的分支

0.40主总装把10.3 mm临时解释为“从机器人前脸表面量起”，探头后端Y−81、前端Y−91.3。若实物的10.3实际从PCB面量起，把PCB前表面也放在Y−81，会使PCB与现有前脸实体重叠。

0.41采用另一种**待确认假设**：PCB前表面位于Y−77.5，即前脸内表面Y−78后方0.5 mm。两个探头同步沿+Y内退3.5 mm，经原Ø16.6孔穿出；中心X±13、Z188不变，露出机器人前脸的长度变为6.8 mm。头壳、面板孔、冠盖外形不变，但探头突出量改变，不能说所有外观尺寸都不变。

PCB范围X±22.5、Y−77.5…−75.9、Z178…198；背面元件到Y−71.9。假设探头、PCB、背面器件相加总深度为15.9 mm，**不强行套进来源不确定的15 mm通用标称**。探头与PCB相接只代表候选基准一致，焊脚、真实连接和固定方式未建模。

## 共存结果

前脸内表面到面包板前缘共有8 mm前后空间。候选PCB前间隙0.5＋板厚1.6＋背面4，共占6.1 mm，剩余1.9 mm。若要求至少1 mm名义间距，背面元件预算不得超过4.9 mm；这个上限仍未扣实际公差和变形。

- PCB和4 mm背面占位可与100×85×36面包板静态共存，PCB到前脸0.5 mm、背面到面包板1.9 mm、背面到托盘上缘1 mm。
- 向后预留10 mm接头会侵入面包板8.1 mm，交叠972 mm³，不能按此候选直接装入。
- 顶边12×6×8接头占位可避开面包板；最紧处约为前脸0.5 mm、冠盖0.90 mm。Ø4线束候选沿前上方绕至X54、Y−58的侧边交接区，到面包板1.5 mm、到冠盖约1.60 mm。
- 该路线只到待定交接区，**没有确认与面包板实际接口连通**。端接共有体积归接头，线束包络从接头出口起，不通过忽略碰撞对来放行。

## 拆装条件

静态能放下不等于能把面包板整盘取出。原托盘前缘比面包板前缘多伸出2.5 mm，整盘上提时会扫到候选背面元件和向上接头；不能沿用0.40“已建模部件无阻挡”的结果覆盖新增超声波包络。

主模型的`ElectronicsTray`已增加**前缘让位**：前缘中央宽49 mm、向内2 mm，即X±24.5、Y−72.5…−70.5，去除该处底板和围边。四个固定点、托盘后槽、面包板位置和头部壳体外形保持。主模型只保留采用的几何；旧托盘、后插头等反例由检查脚本临时生成，不留为重复模型对象。

候选拆装次序：

1. 断电并移去冠盖，断开／收置外接线及超声波线束，释放四颗托盘螺钉。
2. 使用前缘让位后的托盘，面包板整组沿+Z上提85 mm；超声波PCB与接头占位可留在前脸位置。保持线束原路径会阻挡，必须先收置。
3. 若要拆超声波，待面包板整盘取出后，释放尚未设计的模块固定件，再将模块向后移11 mm使探头离开前脸孔，随后上提70 mm。

刚性包络检查覆盖整盘连续保守扫掠、超声波后退／上提连续扫掠；圆柱后退沿轴向精确延长，上提采用精确圆柱平移扫掠。保持面包板时先后退超声波会碰撞，是顺序反例。真实固定件、手指、线缆插拔与可抓握位置仍未建模；这不是实物拆装通过。

保存回读、静态和拆装结果见下列正式报告；检查覆盖四个探头分色实体、四处Ø8×90 mm工具杆、整盘和模块的连续扫掠，以及五类新增冲突反例。范围审计逐对象比较0.40：只允许四个探头分色实体内退、托盘前缘让位及四个候选占位新增，其他几何均须保持。
