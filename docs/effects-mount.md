# 0.42 背包外侧本体夹持与底盘薄承板

2026-10-25。用户批准将背包外侧方案补充固定结构后合入主模型。本轮为被动机械结构候选，未设计高压引线、电极、驱动或通电集成。主模型为[CyberTrack.FCStd](../hardware/model/CyberTrack.FCStd)，[专项检查](../hardware/model/effects-mount-audit.json)与[变更范围](../hardware/model/effects-change-audit.json)分别记录路径和几何保留情况。

## 本体夹持

每侧两道分体夹环，中心高度Z86与Z114。内半环、后方连接肋和底托并入背包护壳；外半环可独立拆下，上外半环带顶部轴向限位。本体由底托支撑，上限位防止直接向上脱出；夹持衬垫只按名义接触建模，不假定已具备可靠摩擦保持力。

- 夹环外径31.5、衬垫座孔26.5；内外半环分缝0.6 mm。
- 每半环两个M2.5级候选螺钉，整机共8颗螺钉和8个盲孔嵌件；从各自外侧操作。
- 夹环软衬0.5、底垫1 mm，材料、压缩量、热性能和灌封壳接触位置待实测。没有规定真实螺纹、拧紧扭矩或生产公差。
- 固定结构最外侧X±89.75，收在履带X±114内；最后侧Y107.5，比原后脊条Y97后伸10.5 mm。此前A03裸本体仅后伸0.75 mm，不能继续用于含夹具后的外形描述。
- 固定肋从背包侧壁外侧连接，保留原液瓶舱实体；没有把机械间距、软垫或原湿舱隔板当作高压绝缘／液体隔离验收。

![分体夹环](../hardware/model/effects-clamp.png)

本体拆出顺序：断电并解除、收置待确定的实际线束，托住本体；退出本侧4颗螺钉，分别将两外半环和外衬向外移35 mm；本体向上取90 mm。装入按相反顺序，先核实底垫与夹持区。内衬和底垫留在固定侧，另一模块、两液瓶及现有吸管保持。

液瓶仍按原步骤移开本侧吸管、解绑带后向上150 mm，模块夹具无需拆除。拆装图同时移出多件仅为展示方向，不表示它们连接成一个组件。

## 薄承板固定

顶盖内侧新增4根一体支柱，盲孔向下开口；原顶盖外表面保持。四个固定点为X±39、Y−49／−29，孔距78×20 mm。承板四耳配4颗M2.5级候选螺钉和4个嵌件，螺钉从下方操作。

承板拆出顺序：移去底部维护盖，按既有路径取出充电宝及内托架，断开／收置中央电源线和实际效果板接线；托住承板，退出4颗螺钉，再连同四块板向下取100 mm。充电宝或承板螺钉留装时会阻挡取盘。检修需垫高整机，额外手部空间未建模。

![薄承板四点固定](../hardware/model/effects-tray-bottom.png)

螺钉头最低Z65，距电源顶Z64.5只有0.5 mm名义间隙；承板与电源间距2 mm。MOS包络到顶盖最近约1.02 mm、降压板约2.32 mm。这些空间不能再默认容纳未建模支柱、焊脚或接头；须按实物总高、公差和固定方式重新核对。当前固定的是承板，未虚构板卡安装孔；四块板自身可靠固定仍是待完成项。

## 检查与证据边界

生成脚本：[effects_mount.py](../scripts/effects_mount.py)，由[主模型构建入口](../scripts/build_tank.py)调用。范围审计使用明确的0.41基线，要求原309对象保留，其中307个几何不变；只允许在背包护壳和顶盖指定区域增加夹持支撑／内柱，不允许删除原实体。头壳完整几何与前斜坡外表面保留。

专项覆盖新增实体静态干涉、既有维护空间、两本体+Z90连续扫掠、承板−Z100连续保守扫掠、12颗螺钉连续退出、12处Ø3直工具杆及名义接触面。每件外半夹环向外35 mm检查21个离散姿态，不能表述为连续路径全部通过。保留上限位、夹环螺钉、承板螺钉或充电宝的反例应正确阻挡拆卸；整机另回归液瓶、双枪、电机、L298N、头部及既有维护路径。

本次366对象保存回读、1008对静态检查、上述专项和既有维护回归均通过；范围审计确认307个原对象不变。61页图纸第26–27页展示新增固定，第28页索引，N组图卡见55–57页。STEP仅供布局交换：904实体有效，但体积差约3.052 mm³超出0.01阈值，不宣称与原生几何等价。

CAD检查不涵盖手柄／手掌、柔性线束、衬垫变形、拧紧力、强度、制造公差、散热、高压绝缘、EMC或液体共存验收。MT3608、分线器和保护器件未在本轮新增安装占位。

## 方案沿革与清理

A02曾研究中央抬高前舱，用户因下部臃肿否定；A03将裸本体转到背包左右外侧，保留原前斜坡。本轮0.42在该方向上增加夹持及薄承板固定，取代两套独立研究副本。已清理两套旧候选模型、预览、研究脚本及本轮自动备份，共20个文件；原始部件资料与其他历史方案不属于本轮清理范围。文件清单和删除前哈希见[清理记录](../hardware/model/effects-cleanup-audit.json)。
