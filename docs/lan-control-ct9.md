# ct9 局域网网页控制：按住行走

2026-10-25：用户要求在现有 ESP32-S3 上增加手机网页、定时动作、实时状态和全部停止，保留语音。随后用户要求方向键按住持续行走、松开停止。当前源码版本 `2.0.3-ct9`，替代未部署的 ct8 定时方向键；已完成软件验证、ESP-IDF v5.5.1 编译、仅应用分区烧录及平台角色回读。**实机无负载 HTTP／桌面网页通过；真实手机与语音现场联调待反馈，带载验收未完成**。ct7 已部署及台架记录、ct8 软件报告保留，不转移为 ct9 验收。

## 使用方式

1. 设备连接原有 Wi-Fi；手机位于同一可互通局域网。ESP32-S3 使用 2.4 GHz，手机可以处于路由器桥接的 5 GHz；访客隔离／客户端隔离会阻止访问。
2. 联网时 OLED 的消息区和本地串口 `CT_WEB` 显示 `http://<设备 IP>:8080`；既有语音消息可能覆盖屏幕显示。DHCP 换地址后使用新地址。
3. 浏览器打开该地址，直接点击“连接并接管”，无需配对码。设备必须没有活动动作，也不能已有另一网页控制者；拒绝时不抢占或排队。
4. 按下前进／后退／左转／右转即请求行走，持续按住维持同一方向；松开、移出原按钮、触控取消、丢失指针捕获或键盘焦点时立即发送行走停止请求。支持触屏、鼠标以及聚焦方向键后的空格／Enter；按键自动重复不会再次启动。一次只接受一个方向，换向须先松开，保留停止后 3 秒冷却。
5. 喷水仍选择 1／3／5／10／30 秒，单独点击执行。勾选“按方向键时，同时喷水”后，按下时原子启动持续行走与一次定时喷水；续租不续喷。松开仅停止行走，已开始的喷水继续至原截止时间；全部停止／后台／失联关闭两路。
6. 未行走时状态约每 500 ms 刷新；按住时由每次续租回执刷新，显示“按住行走”，不将 600 ms 租期显示成用户动作时长。底部“全部停止”、BOOT 和语音停止始终可以结束两路。关闭页面、锁屏、切后台或行走中窗口失焦会尝试停止并释放，重连／返回不自动续走，须重新接管并按下。

“松开停止”表示浏览器立即发出停止请求、设备处理后关断；网络和机械惯性使其不能等同于零延迟实体停车。停止包丢失时由设备端 600 ms 行走续租截止兜底，实际响应与停车时延待板上测量。

只支持 IP 地址访问，当前版本不启用 mDNS。8080 与原配网 HTTP 服务及控制端口分离。页面、CSS、JS 内嵌应用，无 CDN、字体下载、App 或独立服务器。取得 Wi-Fi 地址后，网页功能独立于云端语音会话；本地互联网断开仍可操作的设计需板上验证，云端语音仍依赖互联网。

## 控制权与输出约束

- 连接成功即取得单网页控制权。接管会取消应用队列里尚未执行的语音票据；原音频会话的已见 RPC ID 历史保留。网页序号独立，不占用语音的 128 项记录表。
- 网页接管期间语音对话、查询状态、全部停止保持；语音动作拒绝。网页释放后，已建立的语音会话可接受新的明确动作；没有语音会话时按原方式唤醒，不补做旧命令。
- 云端音频通道关闭／错误只撤销语音入口；网页接管时不因此停止网页动作。Wi-Fi 断开关闭两路、撤销网页会话并清除语音在线状态。重启／OTA 入口锁定全部动作；OTA 失败也不会自行恢复，需正常恢复流程。
- 网页控制权心跳租约 **2000 ms**；持续行走另有更短的 **600 ms** 截止。两者均由原优先级 10、5 ms 控制任务检查。控制权租约过期时停止并释放；行走租约过期时停止两路并取消长按，控制权可保留至原 2000 ms 截止。两者均取消相关待执行请求。停止响应仍受调度、驱动及硬件影响；2000 ms 是软件策略期限，不能声称是已实测的实体停止时延。
- 按住行走：浏览器等待上次回执后约 **150 ms** 发下一次续租；一次最多一个续租请求在途，短请求超时 400 ms。续租必须携带当前 `hold_id` 与设备回执的单次 `renewal`，重复或旧续租不能延长期限。600 ms 到期关闭两路且作废长按，状态心跳本身不能续走；续租只更新电机截止时间，不重复初始化 PWM、不增加启动计数、不改变喷水时长。停止后的迟到续租不能重启动作。
- 每次有效状态心跳签发新的 `window`；动作必须匹配当前窗口，且距签发不足 **1500 ms**。持续行走的开始请求进一步要求窗口年龄不足 600 ms。窗口只使用一次；动作序号必须严格递增，失败请求也消费序号。不缓存后补、自动重试或断线重放。STOP／BOOT 使已有窗口失效，防止滞留命令在停止后启动。
- 语音及保留的定时 HTTP 行走／转向仍为 1–3000 ms、约 60% PWM；网页长按在有效续租期间允许超过三秒持续运行，约 60% PWM 不变，连续带载／温升尚未验收。喷水 1–30000 ms。两路独立截止，行走冷却 3000 ms、喷水冷却 1000 ms；定时动作不续时，长按只延长当前同方向租期，不运行中换向；组合须全部就绪，否则整体拒绝。
- HTTP、语音、BOOT 共用同一带优先级继承的互斥锁与输出驱动。网页响应在释放锁后编码／发送，截止任务不做网络、显示、日志格式化或堆分配。HTTP 请求不进入语音应用任务队列。
- `logical_outputs`、方向、剩余时间、冷却等均为固件逻辑状态，无轮速／水流反馈。30 秒仍是软件上限，不代表完成 30 秒连续带载验收。GPIO、供电支路及高压实现边界保持原样。

## HTTP 接口

所有 API 均为 POST，`Content-Type: application/json`、`X-CyberTrack-Client: 1`；接管接口外还需要 `X-CyberTrack-Token: <token>`。只接受设备当前 STA IPv4 的 `Host: <IP>:8080`；提供 Origin 时必须精确同源。无 CORS／OPTIONS 放行，不支持通过域名或反向代理访问。

| 路径 | 请求体 | 行为 |
|---|---|---|
| `GET /` | 无 | 内嵌控制页面，不嵌入会话令牌 |
| `/api/pair` | `{}` | 无需 PIN，空闲时接管；返回 `result=ok`、128 bit 随机十六进制 `token` |
| `/api/state` | `{}` | 核验现有租约、续心跳、签发新窗口，返回状态；已超时的租约不能续活 |
| `/api/action` | 下列严格参数 | 校验当前来源、序号／窗口、类型／范围后执行；开始动作须 `result=accepted`，续租须 `renewed`，松开停止须 `ok` |
| `/api/stop` | `{}` | 全部停止并作废旧窗口，保留网页控制权；不受动作序号／窗口门槛约束 |
| `/api/release` | `{}` | 全部停止，释放控制权并撤销令牌 |

原定时动作与 `drive_start` 共有字段为 `operation`、`sequence`、`window`，其中后二者是 1–4294967295 的整数；序号由浏览器在该会话内递增，窗口来自最近一次状态响应。其他字段：

| operation | 额外必填字段 |
|---|---|
| `drive_start` | `direction`；可选 `water_duration_ms`（整数 1–30000）。没有行走时长参数；成功时 `drive_hold_id=sequence` |
| `drive_renew` | 只传 `operation`、`hold_id`、`renewal`，后二者为非零 uint32；不传 sequence/window/direction。成功必须 `result=renewed`，回执提供下一次 renewal |
| `drive_stop` | 只传 `operation`、`hold_id`；无窗口期限门槛，记录已取消的开始序号，避免松开包先于启动包到达后误启动。旧 hold 的松开包不停止较新的 hold；正常成功 `result=ok` |
| `move` | `direction`（forward/backward/left/right）、`duration_ms`（整数 1–3000） |
| `water` | `duration_ms`（整数 1–30000） |
| `move_and_water` | `direction`、`move_duration_ms`（整数 1–3000）、`water_duration_ms`（整数 1–30000） |

缺失、额外、重复字段及非整数／越界值拒绝。请求体最多 384 bytes，逐段接收，接收／发送 socket 超时为 1 秒；服务器最多两个客户端连接，配置栈 8192 bytes。超时不是端到端延迟保证，短时阻塞仍由独立租约任务兜底。

状态沿用 ct7 回执，并增加 `control_owner`（web/voice/none）、`window`、`move_cooldown_ms`、`water_cooldown_ms`、`boot_held`，ct9 另增加 `drive_hold_id`（0 表示未长按）、`drive_renewal`、`drive_lease_ms=600`。长按时 move_remaining_ms 是续租剩余，move_last_duration_ms 为初始 600 ms 租期，不表示总行走时长；语音仍按原定时语义读取自己的回执。`request_sequence` 是所有回执共享的启动期计数；页面忽略晚到的旧回执。会话令牌不出现在语音状态或动作日志中；轮询状态和持续行走续租不逐条打印日志。

HTTP 400 表示参数／请求体错误，401 表示无效或过期会话，403 表示 来源不符，409 表示接管失败，429 表示接管限流（全局最多每秒一次尝试）。通过传输验证后的动作拒绝可返回 HTTP 200，仍须检查 `result`：`stale_request`、`duplicate_request`、`not_ready_or_busy`、`drive_cancelled`、`output_fault` 等不表示执行成功。发送回执失败时尝试释放当前网页会话，无法检测的丢包由租约处理。前端发生请求异常后停止续心跳并尝试释放，不自动重试动作。

按用户的开发阶段要求，本版取消配对码：同一局域网内能访问设备的客户端均可在空闲时接管，没有身份认证。保留同源检查和内存会话令牌，用于单页面控制权、停止与续租，不作为局域网访问身份限制。采用 HTTP，无 TLS；页面令牌不写 URL、cookie 或 localStorage。

## ct9 部署与实机无负载复测

2026-10-25：已备份 ct7 应用及头部配置区，确认板卡、分区与 OTA 选择后，仅写入 `0x20000` 的应用。首次刷写后头部 128 KiB 与备份逐字节一致；首次启动后正常云端配置流程刷新了 websocket token，最终回读其余 59 个 NVS 条目、引导、分区、OTA 与 PHY 数据不变。没有擦除配置或写入 assets。修复许可编码后的有 PIN 中间镜像为 2,596,640 bytes，SHA-256 `c7743c2d85557a87f71e0207e9b4a359d4d7ca660fed02497471126f44b74133`；随后用户要求取消 PIN，最终镜像见部署记录。
