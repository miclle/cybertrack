# 0.41 面包板整组浅托盘

2026-10-25。用户要求保留现有面包板与 ESP32-S3、扬声器、麦克风、小屏幕的接线，按左右 **100 × 前后85 × 高36 mm** 整组包络规划，保持头部外形，暂不考虑电弧模块。本页替代旧裸板托架、独立扬声器和电弧模块在头舱内的安装说明。

本页保留0.41头部结构记录；0.42主总装保持这些头部几何，新增背包夹持和底盘承板，见[当前结构](effects-mount.md)与[范围审计](../hardware/model/effects-change-audit.json)。

100×85为用户提供的面包板平面尺寸；36为用户批准的规划高度，尚不是包含所有元件、插头和线束的实测总高。模型不虚构组内板卡、屏幕和音频器件位置，也不将原裸ESP32-S3的供应商资料套作现有面包板的安装接口。

0.41已将[超声波向上出线候选](ultrasonic-head.md)合入主模型和PDF，并增加托盘前缘中央49×2 mm让位；四个固定点和后槽保持。取盘前必须断开／收置超声波线束。新增包络及拆装已纳入本版检查，实物接口与模块固定仍待确认。

旧小托架、排母、防脱压架、四个托板旧固定点、独立扬声器和前上方电子占位撤出当前模型；组内设备统一由完整包络表示。0.40当时移除了两个电弧圆柱；0.42本体已转至背包外侧机械夹持区。冠盖脊翼及非通电标识保留外观，不表示电弧功能已集成。

浅边只限制横向滑动。板底厚度与可接触边缘尚未知，不增加可能压住元件／跳线的假定压片。两处底座边缘防脱固定需在实物确认后细化；当前不能据此放行振动、翻转或行走试验。托盘材料、柱根强度、打印方向、嵌件和螺钉有效啮合未验证。

## 拆装顺序

1. 断电，卸4颗冠盖螺钉；整体冠盖沿+Z上取65 mm。
2. 断开并收置超声波及其他对外线束，保留面包板内部跳线；实际插头和松弛长度待试装。附近液管按既有整机维护前置条件收置。
3. 从板外四处侧耳上方操作，卸下4颗托盘螺钉；各沿+Z退出20 mm。
4. 承托托盘，连面包板整组沿+Z上提85 mm。不要通过跳线提拉；实际抓握空间另验。
5. 装回时先检查后槽线束没有夹在承台、孔位或冠盖分缝中，固定托盘后再接线并合盖。

上提路径不要求把组内元件逐一拆下，但不承诺对外线束不断开即可整盘取出。原裸板的USB拔插和天线审查区已撤销，不能沿用它们的通过结论；屏幕观察、麦克风收音、扬声器出声、USB插拔和整机RF需要现有实物布局输入。

反例要求保留冠盖或托盘螺钉时检出阻挡，以及组件高度增加5 mm时检出冠盖干涉。几何结果不能代替实物适配、制造公差、材料强度、线束应力释放、防脱保持、声学、RF、电气或儿童使用验收。
