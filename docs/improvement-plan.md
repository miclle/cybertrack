1. **基线与验证入口**：I10，收敛当前能力，保留历史记录，建立阶段证据。
2. **上手、语义与回执解释**：I02、I03、I08，同时准备 I01、I04、I05、I09 的真实采集材料。

4. **编排与泡泡表演**：I06、I07。先完成设备侧确认与取消约束，再接 UI 和自然语言；不以提示词代替执行限制。
5. **硬件架构与设计收敛**：I12，联合 I04／I05／I09／I11，先形成电源树、预算、接口与部件建模依据，再决定实际器件或结构变更。
6. **现场收敛**：完成前述现场项目及实际结构改进；用户具备条件后执行，不提前声称总体目标完成。

每阶段提交仅包含本范围文件，并记录检查命令、结果及限制。编译与主机检查不自动刷写设备或更改在线角色。当前已部署版本见[当前状态](current-status.md)，源代码发生变化时须更新候选状态。

## 产品与原创性

家长负责首次连接、动作启动和停止，孩子可参与命名、编排和观看；具体年龄与使用环境待用户研究明确。首轮亲子体验不包含点火；当前样机不宣称已通过儿童使用验收。

核心体验围绕小D 的角色、履带与泡泡编排；电路工作台和芯片模拟器不是本阶段产品目标。SolidCue 是用户已有的独立工具，本项目新增价值是将空间评论、原生修改、回读和恢复接入 CyberTrack 单件设计；不将既有上游能力描述为本项目从零实现。

用户体验指标是探索目标，未达标应修改假设而非补造结果。性能和成本以实测与实际采购为准；不得凭百分比 PWM 承诺轮速、角度或位移。
