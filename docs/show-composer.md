# 泡泡表演编排

I06／I07 交付按设备契约、网页编辑与模板、灵矽／真人验证分阶段进行。**ct45 已仅应用部署，角色已同步灵矽。** [设备验证](../firmware/esp32-audio/startup-ct45.json)通过草稿创建、单步隔离修改、旧版本拒绝、删除、取消、停止／释放失效和重连不恢复，39 条回执均零启动。有效确认执行、实际模型调用与亲子体验分别验收。

## 体验与执行边界

明确进入编排时，先保存草稿，再预览和修改，最后由家长在网页确认。首版仅编排行走和泡泡，保留既有 1–16 步、各步独立速度和时长范围；每步至少一个动作，喷水和点火字段固定为 0。普通直接语音动作仍按现有工具执行，编排模式不替换直接遥控。

草稿接口没有输出调用，保存、查询、替换一步、删除一步均不启动执行器。新草稿或每次修改产生递增版本；无有效草稿时 `revision=0`。编辑必须携带读取的版本，冲突返回 `draft_changed`，不能静默覆盖或自动重试。`replace_step` 只替换指定一步，其余步骤由设备复制保留；删除最后一步拒绝，应明确取消整份草稿。

草稿在最后修改后 5 分钟失效；时钟回退、故障、BOOT／统一停止、Wi-Fi 中断或关机也使草稿失效。网页来源草稿随对应网页会话释放／失租失效；语音来源草稿随语音连接关闭失效。失效后需要重新创建，不恢复旧草稿。仅查询不会刷新草稿寿命。

执行确认由已有网页会话发出，仍需新的设备窗口、递增请求序号和**预览中的确切版本**。匹配的确认只消费一次草稿；即使因通道忙碌／冷却等原因未启动，也不会排队或保留为自动重试。确认后复用现有设备序列调度、间隔与停止逻辑，来源标为 `web`，网页会话断开或失租时取消当前和后续步骤；语音连接变化不取消仍有效的网页序列。统一停止仍优先。

这是网页控制会话内的显式确认，不是家长身份认证。设备不能从语音转写独立证明人的意图；候选角色与评测负责区分“编排”与“直接执行”，本地草稿 API 只保证自身不输出。不能声称任何模型误选普通动作工具都被本机制阻止。

## 网页操作

在设备网页展开“小D 泡泡剧场”。模板只填入本页步骤；“一起说”的台词供亲子互动参考，不会让机器人自动播报，也没有同步表情控制。

| 模板 | 步骤（100% PWM） | 标称总时长 |
|---|---|---|
| 登场 | 前进 0.6 秒；原地泡泡 1 秒 | 1.8 秒 |
| 庆祝 | 左转 0.6 秒与泡泡 1 秒同时开始；右转 0.6 秒与泡泡 1 秒同时开始 | 2.2 秒 |
| 谢幕 | 原地泡泡 1 秒；后退 0.6 秒 | 1.8 秒 |

这些时长是创作起点，不是已验证的位移、转角、制动或儿童使用参数。仍须家长检查场地并观察实际动作。

1. 选择模板，或“载入设备草稿”查看语音创建的步骤。载入会替换本页未保存编辑；轮询不会自动替换正在阅读的预览。
2. 选中步骤，填写方向、行走／泡泡秒数与速度，点“应用这一步”。可追加到 16 步、删除至至少一步。不行走须选“不行走”并填行走 0 秒；泡泡最多 30 秒；时长精确到 0.001 秒。水与点火不进入编排。
3. “保存到设备并预览”只保存草稿。只改一步用 `replace_step`，只删一步用 `remove_step`，整单修改用 `replace`；全都携带原草稿版本。
4. 查看设备返回的步骤和版本，勾选家长核对，再点“家长确认开始”。点击时重新获取设备窗口，版本或内容变化就中止，不发送确认。开始只消费当前版本一次；再次表演必须重新保存、预览和确认。
5. “取消设备草稿”只取消草稿；运行中使用固定底栏“全部停止”或本机 BOOT。页面隐藏、离线及执行中失去焦点会请求释放网页控制；设备仍以会话失租作最终截止。

任何本地表单修改立即清除已勾选的确认；未应用字段不能保存。语音改稿、过期、旧回执、停止、重连或能力缺失不能恢复旧确认。请求串行使用现有设备窗口；失败不重发。编辑内容只存于页面内存，不写浏览器持久存储。

ct53 候选网页可在载入前查看设备新稿。例如，孩子说“结尾的泡泡改成三秒”，家长会同时看到设备待载入的新版本（三秒）和本页预览（一秒）。设备新稿列出完整步骤、并发顺序与预计时长。载入会替换本页编辑，家长需重新勾选才可开始；状态过期时新版预览收起。[候选构建与浏览器验收](../firmware/esp32-audio/verification-ct53.json)

网页状态超过 1.5 秒就禁用确认，设备草稿寿命另行检查；状态轮询不延长草稿寿命。旧固件仍可使用原控制，编排保存／确认保持禁用。网页兼容性不能替代设备或灵矽工具发现验证。

## 设备状态

`capabilities.show_draft=true` 表示设备实现草稿契约，网页据此启用编辑接入。`show_draft` 返回：

```json
{
  "active": true,
  "revision": 7,
  "expires_in_ms": 299000,
  "source": "voice",
  "steps": [{"direction":"left","move_ms":880,"water_ms":0,"bubbles_ms":0,"ignition_ms":0,"speed_percent":100}],
  "nominal_duration_ms": 880
}
```

`nominal_duration_ms` 是各步最长通道时长之和，加步骤间 200 ms，供预览参考，不是实测总时长、转角或位移。调度延迟或中断会改变真实运行。草稿内容由固定存储在互斥锁内复制，JSON 在锁外编码，不在截止任务中分配内存。

执行仍查询 `sequence_active/step/steps/result`，新增 `sequence_source` 区分 `web`／`voice`／`none`。近距离保护取消前进和序列时，已开启泡泡按原独立通道规则结束；残留通道继续保留网页来源，释放网页仍会关闭它，不形成失去所有者的输出。

## HTTP 契约

沿用 `/api/action`、同源限制、令牌与设备窗口，不新增开放端口。示例只说明结构，不能将示例窗口／序号用作设备实测。

```json
{
  "operation": "show_edit", "sequence": 1, "window": 1,
  "draft": {
    "edit": "replace", "revision": 0, "step": 0,
    "steps_json": "[{\"direction\":\"none\",\"move_ms\":0,\"water_ms\":0,\"bubbles_ms\":1000,\"ignition_ms\":0}]"
  }
}
```

| edit | step | steps_json | 行为 |
|---|---|---|---|
| `replace` | 0 | 完整 1–16 步数组字符串 | 创建／替换草稿，返回 `draft_saved` |
| `replace_step` | 1–当前步数 | 只有一步的数组字符串 | 只替换该步，返回新版本 |
| `remove_step` | 1–当前步数 | 空字符串 | 删除该步；剩余必须至少一步 |
| `cancel` | 0 | 空字符串 | 取消匹配版本草稿，返回 `draft_cancelled` |

确认使用 `{"operation":"show_confirm","sequence":2,"window":2,"revision":7}`。`accepted` 只表示执行开始，不能说整段表演完成。直接网页动作若中断正在执行的网页表演，返回 `show_cancelled`，该次不会自动启动新动作。

`/api/action` 最大 JSON 请求体为 8192 字节，以堆内存承载，支持编码后的 16 步；其他接口仍为 384 字节。缺字段、额外／重复字段、非整数、错误索引、超限或不支持的效果均拒绝。原 16 步 JSON 字符串上限仍为 4096 字节。

## 灵矽工具与角色

新增 `self.tank.compose(edit, revision, step, steps_json)`，只负责草稿创建／修改／取消，使用相同解析和版本检查。候选角色要求先查询版本，模糊时长先澄清；保存后简短说明变化，请家长在网页核对。没有语音确认执行工具，不用 `sequence` 或单项动作工具绕过网页确认。普通直接动作仍遵守原默认时长、参数、停止与成功静默约定。

[角色唯一源](../firmware/esp32-audio/role-prompt.txt)已加入编排优先规则，删除旧格式示例以保留平台字符上限内的语义约束。已在灵矽保存并重新打开逐字回读，设备已重启至 ct45；工具远端发现和模型选择不由角色文本回读推定。

[8 条编排增量用例](validation/compose-cases.json)与原 80 条直接动作集分别评分。用例定义模拟状态上下文和允许的工具；禁止在草稿场景调用直接动作，即使总准确率达到门槛也不通过。执行：

```sh

  --corpus docs/validation/compose-cases.json --output output/compose-score.json
```

### ct46 语音改稿的版本检查

语音智能体每次修改或取消前，须调用 `get_status` 读取本设备当前草稿。一次读取只供一次有效编辑尝试使用，30 秒后过期。全停、语音断开或草稿版本变化会使旧读取失效。网页状态轮询不能给语音授权。回执为 `draft_changed` 时保留现稿，并告知家长版本已变。喷水、点火及含糊时长由智能体先说明限制或询问具体秒数；设备仍独立校验步骤和允许的通道。亲子表演的开始入口保持网页上的家长确认。

ct47 在每份 `show_draft` 中附带 `editing_capabilities`，列出允许和不支持的通道以及网页确认入口。即使当前没有草稿，智能体也能从设备回执区分直接喷水和剧场编排的能力。

ct48 将每一步的开始和结束顺序写入预览。例如“后退两秒，同时吹泡泡一秒”显示一步，泡泡先停，后退再持续一秒。若设备存成两步，预览会列出先后动作，含步骤间隔的预计时长为 3.2 秒。家长可在确认前据此修改设备草稿。

## 不连接机器人的屏幕排演

在[灵矽方案参考包](../tools/lingxi-solution/README.md)里双击 `family/rehearsal.html`。也可以在完整仓库运行 `python3 scripts/package_family_rehearsal.py`，用浏览器打开输出文件。页面来自固件中的剧场编辑器，保存与启动只作用于本页内存。屏幕会显示正在排演的动作和步骤，全部停止会终止排演。关闭页面会清空草稿。页面禁用网络请求，不使用麦克风。

初次体验可选“登场”，把第二步泡泡改为两秒，点击应用、保存排演草稿，再由家长勾选并确认。下一轮自由选择其他模板或自己改编。主持人另开[观察单](../tools/family-study/observer.html)，载体选“无动作原型”。此入口可观察理解和主动选择；三分钟实机上手及停车仍须在现场测量。

已在断网 Chromium 的 320、390、1280 像素视口使用实际生成文件验证三个模板、单步改稿、确认、第二步的屏幕提示、中途停止和重新排演，未产生 HTTP 请求。[浏览器检查](../tools/family-study/rehearsal_test.mjs)

对于可识别但没有量化时长的相对改稿，ct67 候选返回 `draft_duration_unspecified` 与 `clarification_facts`，保留草稿并要求具体秒数；同轮不能通过其他工具补做。量化归属、未知说法和过程播报仍待修，当前部署范围见[版本状态](current-status.md)。[门禁与验证](validation/relative-draft-duration.md)
