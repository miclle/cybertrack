## 面包板接线候选

先断开 L298N 12 V 和 MOS 5 V，再断开主控供电后迁线；不带电插拔。原台架控制器的六根控制线全部移除，不把两块 ESP32 输出并联。

| 面包板 GPIO／端点 | 连接 | 说明 |
|---|---|---|
| IO8 | L298N ENA | A 路使能 PWM |
| IO9 | L298N IN1 | A 路方向 1 |
| IO10 | L298N IN2 | A 路方向 2 |
| IO11 | L298N ENB | B 路使能 PWM |
| IO12 | L298N IN3 | B 路方向 1 |
| IO13 | L298N IN4 | B 路方向 2 |
| GND | L298N GND | 逻辑共地，电机回流走原功率线 |
| IO18 | MOS TRIG/PWM | 保留原水枪控制线 |
| GND | MOS 控制 GND | 保留原控制地，不接输出侧负极 |

GPIO8–13 在已固定的板级源码中未被麦克风、扬声器、OLED、按键或 LED 使用，仍须确认实物排针空闲与丝印。GPIO4/5/6 是麦克风，GPIO7/15/16 是扬声器；不可沿用独立台架的 4/5/6 与 7/8/9 分配。

L298N ENA／ENB 常高使能跳帽均保持取下，沿用已测试的独立稳压跳帽状态；L298N +5V 不接面包板 5V／3V3。电机维持原 12 V 支路；水枪维持 5 V→MOS→3.7 V 降压→水枪。MOS 输出侧负极不额外接输入负极／面包板 GND，避免绕过低侧开关。不得将 12 V 或 3.7 V 接到 GPIO。

A 接 OUT1／OUT2，候选为车体左电机；B 接 OUT3／OUT4，候选为车体右电机。这里左右是机器人自身视角。`forward` 对应 A、B 的 IN1／IN3 高及 IN2／IN4 低；镜像安装时两侧轴从外部看可能相反。必须空载核对每侧带动车体向前的方向；需要交换某电机两根输出线时先断开所有电源。台架“正转”不自动等于车体前进。

两路使能没有外部下拉的既有条件仍需保留：面包板先启动并确认关闭，驱动功率最后接通、最先断开；内部下拉不能证明复位、启动前或失电时保持关闭。本轮不做功率带电的刷写／复位测试。

## 灵矽工具及停止

| 工具 | 参数 | 行为 |
|---|---|---|
| `self.tank.get_status` | `{}` | 查询两路电机、水枪、剩余时间及故障 |
| `self.tank.stop` | `{}` | 立即取消全部动作与排队请求，两路使能／方向和 MOS 关闭 |
| `self.tank.move` | `direction`、`duration_ms` | `forward/backward/left/right`；1–3000 ms；约 60% PWM |
| `self.tank.water` | `duration_ms` | 1–30000 ms；保留原 MOS 水枪 |

角色将明确动作但未说时长的请求设为一秒；超限只请求单次上限并说明，不分段补足。左／右为两电机反向的原地转向，不是角度控制。电机结束或停止后冷却三秒，水枪一秒；冷却时间不代表实测轴已停稳。两类动作互斥，忙碌请求拒绝且不排队补做。BOOT、停止和已检测断线均关闭所有动作，释放／重连不会恢复。

共享 128 项会话 RPC ID 记录和内部票据：一次接受会取消同时排队的其他请求；停止／断线取消旧票据，队列超过五秒拒绝。无跨复位持久化保证。输出 API 出错锁定，尝试全关，不自动重启或重试动作。状态、时限、错误字段详见[面包板适配](../firmware/esp32-audio/README.md)与[接口手册](../firmware/CAPABILITIES.md#面包板-ct6-接口)。
