## 当前工程假设（可调整）

- A01：首版固定枪管及固定炮塔外罩为暂定布局；已新增 MG90S 采购记录，其用途尚未指定，待明确后再决定旋转／俯仰自由度。
- A02：先验证人工监督下的低速短动作，不设自动导航、追逐或瞄准功能。
- A03：固件拟用 ESP-IDF，首版采用 WSS 与端侧 MCP；主控已指定 ESP32-S3 N16R8，具体板型、SDK 版本和音频器件未定。
- A04：动作默认关闭，本地使能与物理停止独立于云端；首轮组合效果禁用，逐项验证后开放。
- A05：充电宝低置，水与泡泡液分仓，补液无需穿过电子仓；具体结构由实际尺寸决定。

- A07：固件先以不依赖硬件的 C11 控制核心和主机测试并行开发，再做离线协议适配；板级工程及实际输出等待相应硬件证据。实施顺序见[固件计划](../firmware/PLAN.md)，测试限制值不是物理运行参数。
- A08：F1 采用 16 槽 FIFO 原响应缓存、32 KiB 启动期只增防重放过滤器和首次接收元数据；驻留 ID 改写内容拒绝，淘汰或重连后旧动作 ID 仍拒绝。过滤器可能误拒绝新动作，禁止自动清空／换 ID 重试；只读和停止持续可用，跨复位去重尚未实现。跨网络新鲜度证据源未实现前关闭真实动作；具体资源及兼容边界见[离线协议契约](../firmware/PROTOCOL.md)。
- A09：F2 拆分为与板型无关的 F2a 启动／运行层和依赖实物资料的 F2b 适配。F2a 已包含通用输入处理及有界接收队列；去抖参数、队列容量、周期预算和测试回调不作为真实板配置；F2b 先以执行器能力全零验证启动、本地输入、调度与看门狗。见[运行层契约](../firmware/RUNTIME.md)。

上述假设用于推进文档和布局准备，不代表用户已确认所有细节。低压灯光仅是顶部效果的候选替代，未被采纳为最终决定。

## 已发现的资料冲突

1. DF-MD 文件所在资料类别为 V1.3，原理图标题栏却为 V1.4；在线页面逻辑供电条目也分别出现 6–12 V 和 6.5–12 V。以实物版本与对应原理图确认，不能直接拍板跳线或接线。
2. 电机编码器同图两套六针定义互相冲突；电机动力端、编码器 VCC／GND／A／B 必须核实。
3. L 形电机支架图有 `6-Ø3` 与 `6-M3.5` 两种标注；它是可选附件资料，不等于 track-mount。
4. 六角联轴器图中“12 mm”对边／对角基准不清，中心孔“4 mm”不能直接认定 M4。
5. 安装件缺口深度与对称性未实测；尺寸 JSON 明确保留建模假设，不能由 CAD 反推成实物测量。
