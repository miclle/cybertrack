## 当前工程假设（可调整）

- A01：首版固定朝前喷水口、固定头舱及固定颈架为暂定布局；已新增 MG90S 采购记录，其用途尚未指定，待明确后再决定旋转／俯仰自由度。
- A02：先验证人工监督下的低速短动作，不设自动导航、追逐或瞄准功能。
- A03：固件拟用 ESP-IDF，首版采用 WSS 与端侧 MCP；主控为 ESP32-S3 N16R8，已整理 COREBOARD 原理图及排针，实物修订版、SDK 版本和音频器件仍待确定。
- A04：动作默认关闭，本地使能与物理停止独立于云端；首轮组合效果禁用，逐项验证后开放。
- A05：充电宝底部靠近底盘，喷水、泡泡液与电源独立分仓；补液不经过电子区是布局目标，隔液、密封和排液仍待设计。

- A06：0.6 保留已认可的实测充电宝前下方平放位置，120 mm 沿 X、73 mm 沿 Y、31.5 mm 沿 Z，范围 X±60、Y−96…−23、Z33…64.5，包络中心 Z=48.75 mm；端口朝向、线缆空间和实际质心未验证。左右动力模块整体沿 X 外移 +14／−14 mm，内部相对位置与尺度不变。喷水／泡泡液体区各 Ø32 × 70 mm，仍在 X=−24／+24、Y=49、Z43…113；电子区 100 × 45 × 34 mm 原位保留，音频区 72 × 36 × 21 mm 从前舱上层移到头舱 X±36、Y−75…−39、Z146…167。除充电宝外形外均为设计分配；不能由圆柱占位认定整套效果模块能装入。
- A07：固件先以不依赖硬件的 C11 控制核心和主机测试并行开发，再做离线协议适配；板级工程及实际输出等待相应硬件证据。实施顺序见[固件计划](../firmware/PLAN.md)，测试限制值不是物理运行参数。
- A08：F1 采用 16 槽 FIFO 原响应缓存、32 KiB 启动期只增防重放过滤器和首次接收元数据；驻留 ID 改写内容拒绝，淘汰或重连后旧动作 ID 仍拒绝。过滤器可能误拒绝新动作，禁止自动清空／换 ID 重试；只读和停止持续可用，跨复位持久化接口与模拟已完成，真实存储另验收。设备窗口与稳定意图 ID 策略已通过离线模拟，换 RPC ID 不清除意图历史；跨网络认证证据源未实现前关闭真实动作；具体资源及兼容边界见[离线协议契约](../firmware/PROTOCOL.md)。
- A09：F2 拆分为与板型无关的 F2a 启动／运行层和依赖实物资料的 F2b 适配。F2a 已包含通用输入处理及有界接收队列；去抖参数、队列容量、周期预算和测试回调不作为真实板配置；F2b 先以执行器能力全零验证启动、本地输入、调度与看门狗。见[运行层契约](../firmware/RUNTIME.md)。

上述假设用于推进文档和布局准备，不代表用户已确认所有细节。低压灯光仅是顶部效果的候选替代，未被采纳为最终决定。

## 已发现的资料冲突

1. DF-MD 文件所在资料类别为 V1.3，原理图标题栏却为 V1.4；在线页面逻辑供电条目也分别出现 6–12 V 和 6.5–12 V。以实物版本与对应原理图确认，不能直接拍板跳线或接线。
2. 电机编码器同图两套六针定义互相冲突；电机动力端、编码器 VCC／GND／A／B 必须核实。
3. L 形电机支架图有 `6-Ø3` 与 `6-M3.5` 两种标注；它是可选附件资料，不等于 track-mount。
4. 六角联轴器图中“12 mm”对边／对角基准不清，中心孔“4 mm”不能直接认定 M4。
5. 安装件缺口深度与对称性未实测；尺寸 JSON 明确保留建模假设，不能由 CAD 反推成实物测量。
6. ESP32-S3 商品页称 DevKitC-1，板级图纸称 COREBOARD；独立原理图可见标题未标版本，包内另有 V1.4。封面提示天线版本按批次变化；图纸 57.15 mm 为底板长度，63.39 mm 为含图示天线总长，整板高度未给出。GPIO35–37 虽画到排针，但 N16R8 八线 PSRAM 占用，不能作为外设资源。详见[板卡记录](../hardware/components/ESP32-S3-N16R8/README.md)。
