# 产品需求

CyberTrack 是家长陪同使用的双履带语音交互机器人。孩子可以提出表演想法，家长在网页修改行走和泡泡步骤并确认执行。日常语音由面包板连接灵矽，手机通过局域网控制，已有样机和分项现场记录。首次互动流程见[上手卡](quick-start.md)，现行版本、软件与实测范围见[当前状态](current-status.md)。

## 核心需求

编号供机械、电气和固件的[验收矩阵](verification-plan.md)交叉引用。

| 编号 | 需求 | 核对方法 |
|---|---|---|
| R01 | 一台具有个性的双履带交互玩具机器人 | 三视图、实物目检；分层头盔、机械连接与底座具有连贯机甲造型，保留左右双履带 |
| R02 | 采用履带、37R-520、何健弓 L298N 电机驱动板模块、track-mount | 对照 BOM、接口尺寸及拆装路径；双侧传动分别验收 |
| R03 | 控制机器人前进、后退、差速转弯和停止 | 架空验证左右符号，再低速地面验证；停止优先 |
| R04 | 前部自动水枪通电后脉冲喷水，枪口微微上仰；自吸，液管从液舱顶部插入 | 确认模块自带脉冲机制；只控制供能窗口；断电停止并记录残余滴水 |
| R05 | 前部泡泡机自动吹泡泡，自带风扇向前吹；正面看左泡泡、右水枪；自吸，液管从液舱顶部插入 | 前向出口及通风、排液、拆洗检查；停机后滴液与倒流另测 |
| R06 | 两路火花效果，位于底盘前方左右两侧，每侧拟伸出两根线、共四根；两只线圈共用一路 5 V 低压控制，软件单次最多 5 秒 | 先取得正式输出、电流、封装与使用条件；专业安全与 EMC 评估未完成前不进入通电集成 |
| R07 | ESP32-S3 N16R8 接入灵矽，用语音交流与控制 | 配网、绑定、音频往返、端侧工具调用及故障恢复逐项验证 |
| R08 | 新5 V电池包输出分支直供面包板主控 5Vin/GND，并经 DC-DC 升压到 12 V 驱动电机 | 核对容量、端口与分线电流、升压效率、启动瞬态、主控音频稳定性及独立功率断电 |
| R09 | 能停止动作，故障后不自行恢复；同一次识别输入失败后不得自动重试或换工具补做，新输入可恢复，停止始终可用 | 本地物理停止、超时、断网、重启、非法与重复指令试验；输入代际和排队回调回放见[失败隔离](validation/voice-input-guard.md)，实机另验 |
| R10 | 能补液、拆卸电源和维护电机 | 满／空状态布局与独立拆装检查，不让液体经过电子仓 |

## 操作与创作

- 语音支持四方向、60–100% 输出、调速、效果组合和最多 16 步序列。手机支持定时与长按，按来源仲裁，设备本地处理时限与停止。
- 测距提供有效读数、近距离滴声和可选前进保护。保护开机默认关闭，开启时不足 15 cm 停前进，至少 20 cm 解锁后等待新指令。
- 泡泡剧场支持三个模板、修改与版本确认。编排只用行走和泡泡。普通直接动作沿用现行设备工具契约。[表演编排](show-composer.md) · [设备接口](../firmware/CAPABILITIES.md)
- 相对长短的改稿缺少明确目标时长时，应先追问，不由模型擅自选半秒或减半；拒绝后不换工具补做。设备已有[相对改稿门禁](validation/relative-draft-duration.md)和[泛化动作门禁](validation/vague-action-admission.md)，完整数值归属与语义仍按原验收要求核对。
- 模型设计工具支持在整机研究副本上定位、修改和恢复符合条件的零件。开发者可复用角色、设备契约、原理图及验证资料。[模型设计](../tools/solidcue/README.md) · [灵矽方案](lingxi-solution.md)

## 适用范围与目标

首轮亲子体验只使用已核验的行走和泡泡。儿童使用、长期负载、续航与维护成本仍待评估。双火花仅保留低压控制实现及机械预留，A2 禁用该支路装配。用户体验、模型语义与工程效率的衡量方法见 [I01–I13](improvement-plan.md)。具体待办见[项目进展](TODO.md)。
