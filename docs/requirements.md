# 产品需求

CyberTrack 是家长陪同使用的双履带语音交互机器人。用户可用一句话请求多个先后或同时动作；家长陪同观察并随时停止。v2 采用一块定制主 PCB，A1 集成主控、音频、驱动与电源，A2 增加前摄，A3 增加运动反馈，A4 在此基础上改用 4S 电池分域降压。灵矽负责语音交互，手机经局域网控制。已有现场记录来自旧版样机。首次互动流程见[上手卡](quick-start.md)，现行版本、软件与实测范围见[当前状态](current-status.md)。

## 操作与创作

- 语音支持四方向、60–100% 输出、调速、效果组合和最多 16 步序列。手机支持定时与长按，按来源仲裁，设备本地处理时限与停止。
- 测距提供有效读数、近距离滴声和可选前进保护。2026-11-01 用户选择过滤偶发跳值：普通滴声须连续 3 个不同采样时刻的有效读数均小于 50 cm，远距／无效／过期中断确认；仅影响声音准入，避障停车不等待确认。[ct77 修正与部署](ultrasonic-ranging.md#距离提示音) 保护开机默认关闭，开启时不足 15 cm 停前进，至少 20 cm 解锁后等待新指令。2026-11-01 用户补充：对话期间暂缓普通滴声，结束后依据实时有效距离恢复，不补播旧事件；前进停车与紧急告警仍即时优先。[ct74 候选及验收](validation/ct74-deployment.md)
- 模型设计工具支持在整机研究副本上定位、修改和恢复符合条件的零件。开发者可复用角色、设备契约、原理图及验证资料。[模型设计](../tools/solidcue/README.md) · [灵矽方案](lingxi-solution.md)

- 2026-11-01 用户决定移除表演编辑、预览、草稿确认、模板和离线排演。保留语音组合动作、最多 16 步序列和停止保护；仅讨论、预览或要求暂不执行时不得转成直接动作。[退役与验证](validation/evidence/ct78-theatre-removal/no-theatre.json)

## 适用范围与目标

首轮亲子体验只使用已核验的行走和泡泡。儿童使用、长期负载、续航与维护成本仍待评估。v2 已撤销双火花需求及其软硬件接口。用户体验、模型语义与工程效率的衡量方法见 [I01–I13](verification-plan.md#产品改进验收)。具体待办见[项目进展](TODO.md)。

ct70 原始机器人 MCP 编码准入要求：含零字符且可能被 cJSON 截成合法前缀的请求不得触发动作或取消序列；保留合法全停与新输入恢复，公开语义和角色不变。[候选与验证](validation/evidence/ct70-raw-mcp/native.json)

对可识别完整否定句，不得新启动或调速；完全空闲时拒绝误调停止。MCP 没有原始语句关联时，不能用最新否定文本拒绝活动／等待全停，以免漏掉迟到的真实停止。[ct71 候选及未完成边界](../firmware/esp32-audio/verification-ct71.json)
