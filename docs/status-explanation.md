# 上手帮助与“为什么没动”

ct43 引入此能力，现已随 [ct45 部署](../firmware/esp32-audio/startup-ct45.json)；真实平台隔离解释已运行，8/8 只查询，但本组回复语义仅 2/8 满足全部要求，见[诊断结果](validation/lingxi-ct45-20261031.md)。软件检查和编译证据见 [verification-ct43.json](../firmware/esp32-audio/verification-ct43.json)。

## 家长看到的入口

网页底部控制区之后提供“第一次使用 · 为什么没动”。折叠区内有联网、停止与第一次短动作指引，以及基于当前回执的解释；展开不会请求动作或重试。固定“全部停止”保持可见，短屏可以滚动阅读。

解释分别陈述当前状态与最近一次请求：BOOT 按下、设备故障、前进受阻、各路逻辑运行／间隔等待、序列占用，以及上一次动作的接受／拒绝结果。回执未细分 `not_ready_or_busy` 时不会猜测具体原因。没有轮速、水流、电量等传感反馈，不能因逻辑接受声称实际移动，也不能因未移动诊断电池没电。

网页按完整请求往返时间保守计算状态年龄，超过 1500 ms 或断连时显示无法判断。旧序号回执不能覆盖新状态；展开帮助不会刷新动作窗口，后台与重连沿用既有停止规则。

## 设备回执

新增字段：

```json
{"recent_command":{"valid":true,"operation":"move","result":"not_ready_or_busy","source":"voice","age_ms":300}}
```

- 只保留本次开机最近一条**进入动作适配器**的请求结果，来源为 `voice`／`web`；不保存原始语音、身份或完整历史。
- 查询、网页释放和成功续租不覆盖记录；失败续租、停止、调速及保护设置会记录。
- 未进入适配器的 HTTP 认证、JSON／MCP 参数检查失败不在该记录内，仍以对应请求的错误为准。
- 初始 `valid=false`；发生无法计算年龄的时钟回退时 `age_ms=null`。没有有效记录时不能推断原因。
- `age_ms` 描述请求时间，**不是最后停机原因**。请求接受后可能因计时、BOOT、网络或保护停止；不能将旧的接受／拒绝记录当成当前事件。
- 记录在动作互斥锁内复制到固定空间，查询不会改变执行器或请求历史；返回仍是逻辑证据。

`get_status` 工具说明新增只读诊断约定。ct43 引入时角色源未改；后续 ct45 已部署并同步编排角色。真实灵矽已向隔离捕获器发现工具描述，缺回执、忙碌、驱动故障、保护锁定、电量未知、无效距离、序列等待和旧接受回执均有独立诊断。没有动作工具调用，但多例解释仍猜原因或暗示恢复，尚未通过。

## 本阶段验证与退出范围

主机测试覆盖固定记录、字符串生命周期、查询和续租隔离；真实 `Reply` 函数使用真实控制守卫和模拟 IO，检查动作接受／拒绝、查询不覆盖、停止更新及 JSON 解析。网页原脚本覆盖过期、未知、离线、乱序和只读解释；真实 Chromium 在 320／390／1280 宽度下检查展开、滚动、固定停止、无横向溢出和无动作请求。浏览器网络由测试替身提供，不连接机器人。

浏览器检查可在仓库根目录运行 `node firmware/esp32-audio/tests/web_explanation_browser.mjs`，需要已安装 Playwright 及 Chromium；模块不在默认解析路径时，通过 `CYBERTRACK_PLAYWRIGHT_MODULE` 指定其 `index.mjs` 绝对路径。该脚本拦截全部网络请求，仅使用合成回执。

完整固件编译与源码产物核对独立记录。设备语音、实物停止、亲子上手时间和使用体验仍按 [I02／I08](improvement-plan.md)验收；这些主机检查不关闭现场项目。

2026-10-31 角色反馈修正后，同一组原话／合成状态复测 4/8 满足全部解释要求；8/8 仍只查询。缺记录、电量未知已有改善，保护恢复暗示、等待语义及状态概括仍未通过，见[独立复测](validation/lingxi-ct45-role-feedback-20261031.md)。

ct46 候选的 `get_status` 增加 `status_facts`，由固件用当次状态快照和最近一条动作回执生成。它区分当前保护锁定、步骤间等待、驱动或计时故障，以及历史拒绝或接受。接受回执不能解释后来为什么停下，忙碌回执没有细分原因。回答电量及实际动作的问题时，设备明确给出反馈边界。语音模型仍需选取与问题相关的事实，台架、真人和模型的解释准确率分别验收。
