# 面包板 ct7：行走与喷水同时运行

2026-10-25：用户要求取消行走与喷水之间的互斥。此决定替代 ct6 的跨动作拒绝规则，ct6 已完成的台架记录保留为历史证据。本次不改接线、功率上限、速度或通用控制核心；只升级现有面包板适配与灵矽角色。

## 行为

- 行走／转向 1–3000 ms，固定约 60%；喷水 1–30000 ms。各自独立计时与冷却（行走 3000 ms，喷水 1000 ms）。
- 一路活动或冷却不阻止另一路新动作；同一路仍拒绝续时、重复启动和运行中换向，不排队补做。
- `move`、`water` 保留原入参。新增 `self.tank.move_and_water`，参数仅为 `direction`、`move_duration_ms`、`water_duration_ms`，分别使用原范围。两路都就绪才一起接受；任一路忙碌、冷却或参数错误，整个组合拒绝，不执行一半。
- 组合工具在同一次固件回调中启动两路，而非等待两次云端调用；不声明电气边沿精确同步。缺时长的明确组合请求由角色各填 1000 ms，“边走边喷”未说明方向默认前进。
- BOOT、语音“停止”（包括只说停止喷水／行走）、已检测断线、重启／升级及输出 API 故障仍关闭全部动作并取消待执行票据。松开／重连不恢复。此版没有独立停止某一路的工具。
- 同一会话共享 128 项 RPC ID 记录，票据绑定目标通道；启动只取消与本次通道重叠的排队票据，另一通道票据可执行。5 秒过期、跨会话票据失效、表满拒绝保持。

## 输出与回执

输出驱动仅修改变化的通道：开始／结束喷水不重设电机使能，电机开始／结束不拉低 MOS。变更电机方向时先关两路 EN；任一 GPIO／PWM API 错误仍锁定并尝试全部关闭。

| 字段 | ct7 含义 |
|---|---|
| `logical_outputs.left/right`、`water` | 可同时非零／为 true；没有轮速和水流反馈 |
| `capabilities.move_and_water` | true，组合启动工具可用 |
| `move_remaining_ms`、`water_remaining_ms` | 两路各自剩余时间 |
| `move_last_duration_ms`、`water_last_duration_ms` | 两路各自最近一次接受的时长 |
| `remaining_ms` | 两路剩余时间的最大值，兼容汇总字段，不用于单路倒计时 |
| `last_duration_ms` | 最近接受请求的时长；组合请求取两时长最大值 |
| `starts_this_boot` | 两路启动次数之和，单路请求加 1，组合请求加 2 |
| `log_events_dropped` | 非阻塞关闭日志队列溢出数量；非零时日志证据可能不完整 |
| `actuator_backend` | `concurrent_motor_water_bench` |

控制任务仍为 5 ms 周期和优先级 10。关闭事件包含 `channel=move/water`、原因、该路软件运行时间以及关闭时另一通道状态；通过固定长度、非阻塞队列交给低优先级日志任务，避免一路停止时串口阻塞另一路截止检查。日志时间不是实物停止时延。
