# CyberTrack 模型辅助设计

模型辅助设计工具从 CyberTrack 中拆出，现由 [SolidCue](https://github.com/miclle/solidcue) 独立维护。此目录保留接入说明、来源与许可证；安装入口见[操作指南](../solidcue/README.md)。

`scripts/solidcue.py prepare` 将锁定版本下载到被 Git 忽略的 `build/solidcue-src/`，需要该仓库的访问权限。整机快照、研究副本位置修改与恢复、场景校验、材质归档保全及压缩预览已迁回 SolidCue 0.9.3；锁定提交见 [lock.json](../solidcue/lock.json)。历史截图保留，迁回版本的验证范围见[迁回验证](../solidcue/verification-migration-20261101.json)。

历史来源及原始文件哈希见 [UPSTREAM.json](UPSTREAM.json)，许可证见 [LICENSE](LICENSE)，历史修改说明见 [NOTICE](NOTICE)。
