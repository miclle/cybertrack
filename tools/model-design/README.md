# CyberTrack 模型辅助设计

模型辅助设计工具源码由 [SolidCue 独立仓库](https://github.com/miclle/solidcue)维护，CyberTrack 不再内置或在 Git 历史中保留源码。此目录只保留说明、来源与许可证；安装入口见[操作指南](../solidcue/README.md)。

`scripts/solidcue.py prepare` 将锁定版本下载到被 Git 忽略的 `build/solidcue-src/`，需要该仓库的访问权限。当前锁定的上游 0.8.0 不含旧内置版本的整机编辑扩展；历史截图与验收记录保留，但不代表外部版本具备相同能力。

历史来源及原始文件哈希见 [UPSTREAM.json](UPSTREAM.json)，许可证见 [LICENSE](LICENSE)，历史修改说明见 [NOTICE](NOTICE)。
