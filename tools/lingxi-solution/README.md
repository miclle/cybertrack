# 灵矽参考材料包

在仓库根目录执行 `python3 scripts/package_lingxi_solution.py`，生成 `output/lingxi-solution/` 下的本地 ZIP；不会上传、发布或更改灵矽账号。解压后从 `START_HERE.md` 开始。家长和孩子可双击 `family/rehearsal.html` 离线编排，在屏幕上看每一步；主持人另开 `tools/family-study/observer.html` 记录体验。在解压目录运行 `python3 scripts/review_lingxi_reference.py`，可离线核对清单所列文件并分别重算历史基线与 ct57 工具定义各两组真实平台调用的成绩，输出各自的偏差用例编号。`firmware_host_scores` 单列 ct61 原话＋完整固件主机的语义 78/80、编排 6/8，保留首次超时 C005 和额外查询 C008。解压重算仍显示未完成编号与未达门槛，不会用诊断重跑代替失败。三次并发冲突的回执审阅和各主机清单随包提供，完整 RPC 控制重放仍需完整 checkout。返回码 0 表示重算结果与原记录一致。

[明确文件清单](files.json)包含方案章节、亲子上手卡、现用工具契约、角色源、文本／口述用例、采集模板、语义评分器、停止记录分析器、工程修改记录工具、硬件架构、电源预算及模型辅助设计接入记录。`MANIFEST.json` 记录 Git 提交、所选文件是否存在未提交修改、清单之外各交付文件的 SHA-256、源码候选与最近部署应用各自的字节数和哈希。相同输入生成相同字节；已有输出不覆盖。

本包是参考材料，不是完整源码、可刷写固件或完整 CAD 分发。为控制材料范围，不含凭据、设备身份、录音、固件二进制或大体积模型；其他设计资料通过完整仓库继续阅读。文本名单需要人工复核，打包器不会证明任意文件内容都不含敏感信息。当前名单选用无账号配置的工程资料，不采集运行日志和本地 secrets。

198 件整机的本地界面与原生位置修改／恢复已有独立记录；整机宿主卡片消息闭环已完成；真实灵矽隔离文本联调及其失败项见[当前角色回归记录](../../docs/validation/lingxi-role-5991.md)，不能将工具准确率替代回复语义通过。家庭体验和硬件验收仍待完成。开发者可从此包开始检查能力契约、运行语义评分器、停止记录分析和电源预算；新增执行器必须在本地设备重新实现与验证，不由复制角色自动获得。

工程修改记录的开始／结束命令依赖完整 CyberTrack Git checkout；本参考包不包含 `.git`。模型辅助设计的安装命令同样需要完整仓库中的 `tools/model-design/`，本包只含说明、来源、许可证与验证记录。测试使用独立临时仓库，不代表实际工程效率样本。

[ct57 完整回归](../../docs/validation/lingxi-ct57-full.md)与历史基线独立保存。包内 `scores` 是历史成绩，`candidate_scores` 是 ct57 工具定义的记录成绩，后者的回执仍由静态隔离夹具提供。

隔离联调的脚本、诊断集和说明随包提供；包内 `replay/` 只保留评分所需的元数据、用例编号、完成标记和工具调用。打包时逐一核对原始捕获哈希与语料哈希；完整回复与逐轮轨迹从仓库验证记录阅读。工具描述导出依赖完整 checkout 与 prepared 固件源码，联网捕获另需在获授权环境准备依赖和现有设备认证；包内不包含认证信息，也不会自动连接设备。

参考包另附[编排说明对照](../../docs/validation/compose-routing.md)、两份工具定义和十二次会话的审阅摘要。诊断版出现一次未给秒数就缩短草稿，未采纳。其原始压缩轨迹和完整离线诊断命令需要源码 checkout；包内固定集重算仍保留原成绩。
