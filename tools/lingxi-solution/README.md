# 灵矽参考材料包

在仓库根目录执行 `python3 scripts/package_lingxi_solution.py`，生成 `output/lingxi-solution/` 下的本地 ZIP；不会上传、发布或更改灵矽账号。解压后从 `START_HERE.md` 开始。

[明确文件清单](files.json)包含方案章节、亲子上手卡、现用工具契约、角色源、文本／口述用例、采集模板、语义评分器、停止记录分析器、工程修改记录工具、硬件架构、电源预算及模型辅助设计接入记录。`MANIFEST.json` 记录 Git 提交、所选文件是否存在未提交修改、每个文件的 SHA-256 与证据限制。相同输入生成相同字节；已有输出不覆盖。

本包是参考材料，不是完整源码、可刷写固件或完整 CAD 分发。为控制材料范围，不含凭据、设备身份、录音、固件二进制或大体积模型；其他设计资料通过完整仓库继续阅读。文本名单需要人工复核，打包器不会证明任意文件内容都不含敏感信息。当前名单选用无账号配置的工程资料，不采集运行日志和本地 secrets。

198 件整机的本地界面与原生位置修改／恢复已有独立记录；真实模型评测、家庭体验、硬件验收及整机宿主卡片消息闭环仍分别待完成。开发者可从此包开始检查能力契约、运行语义评分器、停止记录分析和电源预算；新增执行器必须在本地设备重新实现与验证，不由复制角色自动获得。

工程修改记录的开始／结束命令依赖完整 CyberTrack Git checkout；本参考包不包含 `.git`。模型辅助设计的安装命令同样需要完整仓库中的 `tools/model-design/`，本包只含说明、来源、许可证与验证记录。测试使用独立临时仓库，不代表实际工程效率样本。
