## 复现

需要完整仓库、两份原生模型和带 NumPy 的 FreeCAD Python 环境。macOS 已安装于下列位置时可执行本次使用的命令，输出目录须尚不存在：

```sh
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib \
  /Applications/FreeCAD.app/Contents/Resources/bin/python \
  scripts/check_garage_current_fit.py --output output/garage-fit-new-run
```

[入口脚本](../../../../../scripts/check_garage_current_fit.py)复用既有车库运动检查，读取保存文件并输出独立报告，不依赖桌面文档或正在显示的姿态，不重建车库。模型或脚本更新后需新跑并核对新摘要，不能沿用本次数字。

未覆盖实际五金、打印误差、液体与软管运动、挠曲、承载、摩擦、履带变形、转向和重心稳定性。整机质量、实物试配及坡道进出仍未测；`manufacturing_released` 和 `physical_fit_verified` 均保持 `false`。没有因此授权打印或通电测试。
