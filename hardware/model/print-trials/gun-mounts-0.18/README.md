# 泡泡枪与水枪支架 STL：0.18 试装版

来源为已推送的 `91f11fc` 提交中的整机 0.18 快照；未读取并行任务正在重建的工作区模型。完整提交号、源文件 SHA-256、导出对象、姿态变换及网格回读见 [readback.json](readback.json)。本套文件用于先打印支架、试配真实枪体；未作为强度或整机制造验收。

## 打印件

| 文件 | 内容 | 数量 | STL 外形 X × Y × Z（mm） |
|---|---|---:|---|
| [bubble-gun-bracket.stl](bubble-gun-bracket.stl) | 泡泡枪底座、整体前圆环、两段槽壁及前后止挡，融合为一件 | 1 | 50 × 68 × 43.55 |
| [water-gun-bracket.stl](water-gun-bracket.stl) | 水枪底托及尾线导向鞍，融合为一件 | 1 | 46.2 × 98.5 × 33.3 |

STL 不内嵌单位，导入切片软件时选择 **毫米、100% 比例**，核对上表尺寸。四件分别移到原点并落在 Z=0；支架底面朝下，压盖翻转后以较大的平面朝下。整机中的 5° 安装倾斜已解除，这是打印摆放变换，未缩放或修改零件形状。导出摆放不表示免支撑，切片时检查圆环内侧、压盖和局部悬空区域的支撑预览。

## 试装时补入的软垫和紧固件

- 泡泡枪槽底仍预留 **0.6 mm** 软垫；未把软垫融合成硬质塑料。前圆环孔径 34 mm，枪口直径 31.5 mm，名义径向余量 1.25 mm；后槽净宽 6.4 mm、前槽净宽 10.4 mm。
- 水枪两处夹持位置，各需底部 **1 mm**、上部 **1 mm**、内侧 **0.6 mm** 的软垫。未加垫时不能据松紧判断最终配合。前底垫需避开基座螺钉工具孔。
- 螺钉与金属嵌件没有导出成塑料；现有 M3 级候选孔保持原尺寸，不是已定型的自攻孔或热熔嵌件安装孔。肩梁及其安装柱属于整机，本包不含这些部件。
- 先不涂胶试配泡泡枪，确认环、槽和止挡的位置，再按既定方案用可接近清除的胶点辅助固定。原 35.8 mm 总高与 4.7 mm 支承间距的推导差异，以及前底轮廓／薄片偏置仍待核实。

## 检查范围

四件在融合后均为单个有效 CAD 实体；STL 写出后重新读取，检查封闭、单连通体、非流形、自交、正体积、边界尺寸和网格近似体积误差。网格采用线性偏差 0.03 mm、角度偏差 0.10 rad。结果见回读文件；打印收缩、孔径补偿、软垫压缩、胶粘保持及倾斜带液工作尚未实测。

## 再导出

在仓库根目录运行：

```sh
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib \
/Applications/FreeCAD.app/Contents/Resources/bin/python \
  scripts/export_gun_mount_stl.py --revision 91f11fc
```

脚本从指定提交一次性提取整机和报告，在临时目录中只读打开，避免并行保存导致版本混用；不写回整机文件。
