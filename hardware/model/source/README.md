# 合并打印设计源档

`CyberTrack-design.FCStd` 保留六个融合件的可编辑关系、58个源特征、59个隐藏检修／工具／避让空间以及原组织分组，用于生成器检查与旧特征图卡追溯。它是主模型树展平前的原字节保存，不是另一套布局方案。

日常查看、选件及打印请使用上一级的 [CyberTrack.FCStd](../CyberTrack.FCStd)：只保留“01 双履带与动力参考”分组，其余对象全部一级显示；58个重复输入及59个隐藏检查空间不再进入交付主模型；20个设备／线管占位仍在主模型中默认隐藏。

`build_tank.py --render` 先生成并验证完整设计，再由 `model_tree.py` 更新此源档及主模型。[树结构审计](../model-tree-audit.json)记录两文件哈希、清理清单和逐对象几何一致性。旧专项报告中的源对象名称及几何哈希对应本源档；主模型的等价关系由树结构审计给出。
