已切片 3MF（历史中间文件 `PP07-P2S-PLA-0.20.3mf`，已清理）包含头部下壳、前脸和固定装饰，冠盖与托盘另打。重新切片时须核对实际材料与热床类型。本轮只准备本地文件，没有发送或启动打印。

- P2S／0.4 mm 标准流量喷嘴，Generic PLA，纹理 PEI。
- 开口向上，179 × 122.5 × 55.1 mm；4圈墙、15%陀螺仪填充、0.20 mm层高、5 mm外侧brim、无筏层。

- 预计约 **7小时16分、177.1 g**，含支撑等耗材，属于切片估算。
- 切片成功，无未支撑悬空警告；STL闭合、单连通且无非流形边。输入哈希与三种摆向比较见[报告](report.json)，原始切片结果见[result.json](result.json)。支撑实际清除、孔径、外观和层间强度仍需打印检查。
