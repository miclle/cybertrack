# L298N 紧凑固定与接线候选（0.57）

2026-10-26。适用于两电机尾部净距 **30 mm**、两台安装面至尾部均 **57 mm**，以及用户新测的 **L298N 插上控制线后最大总厚度 28.5 mm**。取较小的直接净距，未把 CAD 面距推导的 32 mm 当成可用空间。原来的 27.5 mm 裸包络检查已经被本次接线包络取代。

正式总装与设计源档同步为此候选；电机、履带及其固定接口保持。当前完成的是几何、紧固方式和接线空间设计，仍需局部实物试配。

## 固定方式

- 板卡绕 Z 转 90°，厚度朝两台电机；接线包络为 **X−14.25…14.25、Y−21.25…22.25、Z36…82.2 mm**，居中时距假设尾部检查盒每侧 **0.75 mm**。
- 相对前一布局研究，板卡下沿抬高 4 mm。底部托架由底盖承载，用 **2 颗 M2.5×8 螺钉和 2 颗 M2.5 螺母**固定；不再由顶盖的旧吊柱承重。
- 前后限位、四角侧向绝缘垫、下承托垫和可拆上压框约束板卡。压框用 **2 颗 M2×4 螺钉和 2 颗 M2 薄螺母**锁紧。薄螺母选型包络为对边 4 mm、厚 1.2 mm，尺寸参考 [Accu 的 DIN 439 M2 薄螺母规格](https://www.accu.co.uk/thin-hexagon-nuts/73069-HFN-M2-A4)；这不是用户已有螺母的实测值。
- 上压框底部开两条工具槽，允许机外拧螺钉和轴向退出；取掉压框后板卡可竖直取出。前端没有突出螺钉，避免下取时扫到电池。
- 底盖新增两处 Ø2.9 通孔，顶盖取消旧吊柱并增加前侧 12×2 排气开口；未打通后湿舱隔板。原底盖六个固定点保持。
- 托架在电机尾部对应的中段保持窄截面，前后端局部侧挡较宽；不能把整件最大外宽直接当作侵入电机间隙。模型已分别检查这些位置。

PCB 孔位没有实测，故未使用假设孔距。软垫均为候选接触位置：底垫厚 0.8、端面垫厚 0.25、侧垫厚 0.5、上垫厚 0.3／0.5 mm。压框的几何接触不证明实际 PCB、焊脚和散热片存在安全受力面；试装时须检查每块垫实际压在哪里，并调整垫厚。底盖承载、打印层向和螺纹防松未做载荷试验。

## 接线空间

| 空间 | 设计范围／截面 | 用途 |
|---|---|---|
| 下沿空间 | X±6，Z32.9…35.5，厚 2.6 mm | 下沿线材转接；不将此尺寸称为容纳整只插头的空间 |
| 前端通道 | 宽 12、前后厚 2.2 mm，Z35.5…61 | 前侧电机引线向下转入底部通道 |
| 后端通道 | 宽 14、前后厚 2.4 mm，Z35.5…85 | 电源、控制及后端引线汇集上行 |
| 顶部汇接 | X±7，Y6…24.8，Z84…88 | 与现有 Ø10 中央线束预算相接 |
| 两侧电机出口 | Z82.5…84.7 横向分支，X±23；两侧转至 Z70.5…84.7 | 从板卡上方绕至电机尾部旁的接线交接区 |
| 排气预留 | X±6、Y−19…−17，Z82.2…94.5 | 绕开上压框和固定颈架，经新增顶盖开口排出 |

以上是连续连通的空间预算，线材应摊开走，不额外挤进两侧 0.75 mm 的窄缝。用户测得的 28.5 mm 用于已插接的模块总体包络；插头和真实端子没有拆分建模。线径、线束排列、弯曲半径、线长及每个引脚的末端连接尚未测量，不把几何通道视为电气线束验收。现有 Ø10 中央通道及电气针序未改。

## 装配与检修

1. 在机外装好托架底部螺母、四角软垫及板卡，确认没有金属件压住焊脚或元件。
2. 装上压框及两颗 M2×4 螺钉，核对实际板卡的夹持情况；端子螺钉在机外操作。
3. 用两颗 M2.5×8 将托架固定到底盖。按前后通道安排线材，再将底盖与板卡整组装入，锁紧底盖原来的六颗螺钉。
4. 检修先断电，承托底盖并释放六颗底盖螺钉。断开可触及的线束接头，或使用经实测足够的检修余线，再将整组沿 −Z 取出。
5. 机外拆两颗上压框螺钉、上提压框，再竖直取出板卡。底盖与托架之间的两颗 M2.5 螺钉只在需要分离这两个打印件时拆卸。

当前连续扫掠涵盖整个刚性组件和底盖，**没有证明带着已固定线束可以直接拉出 80 mm**。线束快拆位置与检修余线需在试装时确定；不额外假设中央通道中的整束线可自由抽动。
