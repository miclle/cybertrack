## 原理图回读

以下是两份板级原理图的连接，不代表实物逐网匹配；到货板稳压器标记为 `1117 3.3V`，与图纸 U3 标注不同。方位参照尺寸图：元件面朝向观察者，天线在上、两个 USB 口在下。

| 电路 | 图纸连接 | 对后续适配的意义 |
|---|---|---|
| 主模组 U4 | ESP32-S3-WROOM-1；供电网 VDD33；EN 网 CHIP_PU | 实物罩体仅见 S3 N16R8；可见 PCB 天线和同轴座，实际射频通路及原厂模组身份未确认 |
| USB1，图示左口 | Type-C → CH343P（U2）→ U0TXD／U0RXD，即 GPIO43／44；带 TX/RX 指示灯 | USB 转串口下载／日志通路；外设不要与桥接芯片争用 UART0 |
| USB2，图示右口 | Type-C D− → GPIO19，D+ → GPIO20 | 原生 USB 通路，GPIO19／20 需预留；具体 USB 功能依固件和启动设置 |
| 自动下载 | CH343P 的 DTR／RTS 经 Q1/Q2（SS8050-G）连接 CHIP_PU／GPIO0 | 资料支持自动复位／下载电路，COM 枚举、ROM 自动连接及无负载固件烧录／复位已通过 |
| BOOT | 按下将 GPIO0 接地，C8 标注 104 | 与启动绑带共用，不能默认作为本地使能键 |
| RST | 按下将 CHIP_PU 接地；R8 为 10 kΩ 上拉，C7 为 1 µF，C9 标注 104 | 板上复位键；不等于独立切断执行器电源 |
| RGB | GPIO48 经名为 RGB 的 0 Ω 电阻接 U1 DI；U1 标注 XL-5050RGBC-WS2812B，5 V 供电 | GPIO48 为板载灯资源；不分配给执行器。例程目录名虽含 38，源码 LED_PIN 实为 48 |
| 5 V → 3.3 V | U3 标注 CJ6107A33GW，5V 网输入，VDD33 输出 | 供电通路已知；可用电流和散热能力不能由型号或原理图直接判定 |
| USB 供电隔离 | USB1 VBUS 经 D1 到 5V 网；USB2 VBUS 经 D2 到 5V 网 | 不据此批准双口并供或带载，仍需核对实物器件和装配 |
| 排针 5Vin | J1-21 经 D3 到 5V；IN-OUT 的 0 Ω 支路与 D3 并联 | 电阻装配会改变反灌路径；确认实物前不混接 USB 与外部电源 |
| GPIO3 选项 | 图中有 USB-OTG 0 Ω 接地支路、USB-JTAG 0 Ω 经 R11 10 kΩ 上拉支路 | 不能从图纸判定实际焊装选择；实物需核对，GPIO3 暂不分配 |

手动下载的资料级顺序为按住 BOOT、按下并释放 RST、再释放 BOOT；芯片规格书第 33 页要求下载启动时 GPIO0=0 且 GPIO46=0。这是资料说明，尚未对本板执行。图中没有批准任何 GPIO 直接驱动电机、水枪或泡泡机。

## 排针表（图纸连接，不是项目 GPIO 分配）

J1 为左排、J2 为右排，各 22 针；从天线侧向 USB 侧编号 1→22。数字是连接器针号，不是 GPIO 号。J1 的 RST 丝印对应 CHIP_PU／EN。背面视图须镜像，不可直接沿用左右。

| 针号 | J1 左排 | J2 右排 |
|---:|---|---|
| 1 | 3V3 | GND |
| 2 | 3V3 | U0TXD / GPIO43 |
| 3 | CHIP_PU / EN | U0RXD / GPIO44 |
| 4 | GPIO4 | GPIO1 |
| 5 | GPIO5 | GPIO2 |
| 6 | GPIO6 | GPIO42 |
| 7 | GPIO7 | GPIO41 |
| 8 | GPIO15 | GPIO40 |
| 9 | GPIO16 | GPIO39 |
| 10 | GPIO17 | GPIO38 |
| 11 | GPIO18 | GPIO37 |
| 12 | GPIO8 | GPIO36 |
| 13 | GPIO3 | GPIO35 |
| 14 | GPIO46 | GPIO0 |
| 15 | GPIO9 | GPIO45 |
| 16 | GPIO10 | GPIO48 |
| 17 | GPIO11 | GPIO47 |
| 18 | GPIO12 | GPIO21 |
| 19 | GPIO13 | GPIO20 |
| 20 | GPIO14 | GPIO19 |
| 21 | 5Vin | GND |
| 22 | GND | GND |

资源限制：

- **GPIO35、36、37：N16R8 八线 PSRAM 占用，不可作为外设 GPIO**；即使通用板图画到排针也不能使用。
- GPIO0、3、45、46：启动绑带，先保留；GPIO45 的电压选择还受 eFuse 影响，不能仅凭外部电平推断存储电压。不得为验证本资料改写 eFuse。
- GPIO19、20：原生 USB；GPIO43、44：CH343P 与 UART0；GPIO48：板载 RGB。
- GPIO39–42：默认 JTAG 功能资源，是否释放待调试方案确定。
- GPIO1、2、4–18、21、38、47：图纸中引出、且不在上述占用集合内的后续候选；仍须结合外围电平、复位状态、音频接口与实物版本分配，当前没有项目级 GPIO 表。

## 尺寸与安装基准

以下均为供应商图纸标称值。使用板自身坐标描述，不改变整机 X 向左、Y 向后、Z 向上的坐标约定；装入整机时另行定义转换。

| 项目 | 数值（mm） | 证据／解释 |
|---|---:|---|
| 底板长 × 宽 | 57.15 × 27.94 | 毫米图板轮廓；英寸图 2250 × 1100 mil |
| 含图示天线伸出的总长 | 63.39 | 毫米图自天线顶端到 USB 侧板边；英寸图 2495.63 mil 换算约 63.389 |
| 两排针中心距 | 25.40 | 毫米图；1000 mil |
| 单排首末针中心距 | 53.34 | 22 针的 21 个间隔；2100 mil |
| 排针节距 | 2.54（推导） | 53.34 ÷ 21，不是另行测量 |
| 端针中心至对应板端 | 各 1.91（图纸圆整） | 英寸图 75 mil = 1.905；57.15 − 53.34 = 3.81，解释两端圆整误差 |
| 针排中心至相邻长边 | 1.27（推导） | (27.94 − 25.40) ÷ 2，依尺寸图对称布局 |
| 图示天线纵向伸出底板 | 6.24（推导） | 63.39 − 57.15；不适用于未核对的另一种天线版本 |
| WROOM-1 模组外形 | 18.0 × 25.5 × 3.1 | 型号对比图；**不是整板厚度** |

尺寸图未给出独立螺钉安装孔、排针孔径、PCB 厚度、焊针后总高度、USB 插头和线缆空间、公差。不能把排针孔当作已确认的螺钉孔，也不能将 57.15 mm 当作含天线的总长。后续整板包络优先采用用户实测 **63.6 × 28.2 × 13.2 mm**（含天线总长 × 板宽 × 焊针后总高度）；图纸值保留作对照。安装、插头和射频净空另行验证。本次未修改整机 CAD 占位。
