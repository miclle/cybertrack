# 辰克 5 V 电池包

2026-10-25，用户明确用此电源替代原 ANKER 充电宝，并提供 **116 × 70.5 × 19.5 mm** 外形尺寸。[原始照片](reference/physical-20261025.jpg)保留上传字节，哈希与来源见[sources.json](sources.json)。尺寸为用户输入，不从照片网格或透视比例推算。

| 信息 | 证据 |
|---|---|
| 型号 | 照片铭牌：CK18650-1234S-NP |
| 品牌／品类 | 辰克／可充电锂电池组 |
| 电压标注 | 5 V |
| 正面容量标注 | 16800 mAh |
| 铭牌额定容量 | 12400 mAh（5 V） |
| 铭牌典型能量 | 62.16 Wh／16800 mAh |
| 其他文字 | 充放电分口、USB 充电、恒压输出 |
| 几何输入 | 用户提供长 116、宽 70.5、高 19.5 mm |

照片可见引线从一个短边附近引出，以及红黑线白色插头和黑色圆形接头；具体接口用途、规格、端子极性、引出点坐标、有效线长与安装朝向仍未确认。不能将外观、颜色或型号里的数字当成电芯串并联、充电器或接线依据。输出电流、保护行为、重量与负载能力未知，原 A110M 的 45 W／15 W／373 g 不沿用到此电池。

[独立 FCStd](Battery-envelope.FCStd)和[STEP](Battery-envelope.step)仅为完整长方体包络，无推定电芯、孔位或连接器；长沿 X、宽沿 Y、高沿 Z，原点在最小角。[保存回读](readback.json)核对双格式尺寸和差集。整机 0.48 暂沿用低位平放，范围 X±58、Y−94.75…−24.25、Z33…52.5；位置及短边朝向属于设计假设。新电源端到中央低压线束的具体接入尚未完成，供电验证不继承旧电源台架结果。
