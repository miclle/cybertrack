# DF-MD V1.3 驱动板参考

计划复用一块双路有刷直流电机驱动板控制左右履带。官方入口：[DFRobot DRI0002](https://wiki.dfrobot.com/dri0002)，查阅于 2026-10-23。

- [驱动原理图](reference/DF-MD-schematic.pdf)：**标题栏 REVISION V1.4，日期 2023/1/5**，与目标 V1.3 存在版本差异。图中逻辑电源经 LM1117-5V，不能将其入口与 MCU 3.3 V 混淆。
- [L298 数据手册](<reference/L298 datasheet.pdf>)：归档版本，仅作芯片参考；最新资料另见 [ST 官方文档](https://www.st.com/resource/en/datasheet/l298.pdf)。

这些资料均未证明实物为同一修订版。未导入可直接运行的驱动示例，避免将旧板卡引脚编号误当 ESP32-S3 GPIO。

## 已知接口与限制

官方说明 E1/E2 为 PWM 使能、M1/M2 为方向；使能低为停止。具体左右与正反向由台架标定。使能关闭不代表机械瞬时刹停。

官方资料列出电机支路 4.8–46 V、2 A 电流标称及 47×53 mm 板尺寸；逻辑电源在不同条目出现 6–12 V 与 6.5–12 V。跳线关系、电源入口和控制电平必须与实物版本核对，不能只看板上“5V”或某个芯片阈值决定接线。

两路共用板级散热，2 A 标称不保证密闭车体内两路同时持续工作的温升。12 V 母线经过 L298 后存在压降；测电机端电压、输出、热状态后判断驱动是否满足需求。首次上电前确认默认禁止、控制端不反灌、功率回路和保护；具体连接由匹配实物的电路设计确定。
