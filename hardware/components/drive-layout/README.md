# 双履带动力布局参考

`DriveLayout.FCStd` 是整机生成器使用的独立静态部件包，包含 30 个叶子对象：左右履带各 11 个、两侧电机／轴／联轴器／安装件各 4 个。保留原始尺度与放置，变换为单位变换；X 向左、Y 向后、Z 向上，前方 −Y，单位 mm。

只提取动力部件，不含原参考文件中的底盘、检修盖及四个示意固定螺钉，不携带原装配参数树、外部链接或整机结构。原始混合参考包和旧提取脚本已从项目移至系统废纸篓，可恢复；它们不作为入库资产，忽略规则仍防止误放回。新整机生成只依赖本部件包。

- [原生模型](DriveLayout.FCStd)
- [保存回读报告](readback.json)：输入／输出哈希、逐对象 BRep 比较与必要时的双向几何差集。
- [提取工具](../../../scripts/prepare_drive_components.py)：显式白名单；拒绝覆盖已有部件文件。新增输入时应另存并重新验证。

电机仍是资料尺寸占位，履带与轮组是几何参考，安装件保留原有尺寸假设。有效几何和原位复制不证明传动啮合、张力、紧固、材料强度或实物适配。原有 [track-mount](../track-mount/README.md) 及厂商资料未改动。

0.29另外新增[只读动力固定接口基准](../drive-interface/README.md)，用于重建电机固定面和履带螺钉通道；本包30个对象保持不变，不将固定面补入原部件包。
