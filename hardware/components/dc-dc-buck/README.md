- [背面图片](board-back.png)：可见 `VO+`、`GND`、`IN+`、`EN`，以及 `ADJ`、12 V、9 V、5 V、3.3 V、2.5 V、1.8 V 选择焊盘。

- 两张附件按原字节保存，第三方标识／权利保留；来源、SHA-256 见 [sources.json](sources.json)。这些是商品示意，不是实物焊接状态或仪表读数照片。未覆盖任何已有只读部件资产。
