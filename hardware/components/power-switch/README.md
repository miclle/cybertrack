## 独立模型与安装

[FCStd](PowerSwitch-envelope.FCStd)与[STEP](PowerSwitch-envelope.step)保留部件本地坐标：X为厚度、Y为总宽及拨动方向，Z为安装面向外，以挂耳下表面为安装面Z=0；主体最低Z=−8.3，挂耳暂占Z0…0.5，拨柄最高Z=4。拨柄显示在行程中点，仅用于展示，不代表实际存在中间挡位。[回读报告](readback.json)记录双格式几何检查。

用户要求容易操作且彼此不干扰，并明确排除左右侧面，可考虑头顶、头后面或底盘折面顶盖。0.53采用**底盘折面顶盖中央**，孔组中心X=0、Y=−64 mm，安装面Z=81.1 mm；位置与固定结构见[安装说明](../../../docs/power-switch.md)。滑动方向沿整机X轴，开关从外侧落入本体通孔，两颗塑料用自攻螺丝从上方固定，不用内部螺母。安装座与原折面顶盖一体。

## 电气与验证状态

用途为电源开关；是否直接承载整机电流仍待具体型号的直流额定电压／电流、触点关系和整机启动／运行电流核对。照片和外形尺寸不能证明其总电源切断能力，既有独立执行器断电要求保留。具体接线未定，实物安装、通断、操作手感和温升未验证。
