# 动力固定接口参考

2026-10-25 用户要求沿用 Trackduck 的电机、底盘与履带固定方式及接口参数，保留 CyberTrack 左右各外移 14 mm 的布局。本目录新增独立、只读的功能接口基准，不覆盖既有动力部件包，也不包含原项目底盘外壳或检修盖。

- `MotorInterfaceL.brep`：从指定 `Trackduck.FCStd::LowerChassis` 截取原世界坐标 X59.3…73.01、Y±36、Z28…73 的左侧固定面与连接柱。内侧 0.3 mm 排除旧上护罩的邻接区域；完整 4 mm 固定板的承压座另作几何检查。
- `TrackMountScrewLFront.brep`：原左前履带示意固定螺钉；其他位置由平移／镜像确定。
- [回读记录](readback.json)：源 FCStd SHA-256、截取范围、两份 BRep 哈希与保存回读证据。源文件保持不变。

CyberTrack 左接口相对此基准整体沿 +X 平移 14 mm，右侧镜像。安装端面 X±73，TrackMount 最近面 X±87。坐标均为 X 向左、Y 向后、Z 向上，不再施加旧建模脚本内部坐标旋转。

| 接口 | 沿用参数（mm） |
|---|---|
| 电机固定板 | 厚4；孔分度圆Ø31；六个位置、Ø3.4通孔，其中四个完整承压座 |
| 电机与轴 | 齿轮箱中心Z50；输出轴中心Z57；偏心7；下开槽宽13 |
| TrackMount | 孔距56.2，中心Y±28.1/Z37.4；到电机端面14 |
| 履带紧固 | Ø3.4通孔；Ø5.8×3沉孔；Ø6.2送入通道 |
| 履带示意螺钉 | Ø5.4×2.8头、Ø3杆、4末端啮合占位；长度及接收螺纹未实测 |
| 检修盖紧固基准 | Ø6支柱、Ø3.4通孔、Ø5.8沉孔、Ø2.6×8底孔；头座Z34、承压面Z38 |

0.29重新设计盖轮廓、固定点和底盘外形；当时的独立盖外缘采用X±67.3。0.30保留电机与履带的功能孔位／基准，电机端面改为可拆托座，外部盖合并为一体盖；新的盖孔位和紧固尺寸见当前机械文档，不再沿用本表中的旧盖固定点。制造间隙、材料、真实螺纹与四座承载仍待试验；下方两个电机孔内缘开口，不当作完整座或六点固定。

新版本输入使用 [提取脚本](../../../scripts/prepare_drive_interfaces.py)另行建档，脚本拒绝覆盖现有目录。常规整机再生成只读取本目录及现有动力部件包，无外部仓库运行依赖。0.29端部完整几何对照见[历史报告](../../model/drive-mount-0.29-audit.json)；0.32按孔位、承压面及动力对象保留核对，见[当前报告](../../model/drive-mount-audit.json)，不声明本项目底盘整体与参考底盘形状等价。

0.31取消细长托座，主要承力侧壁、顶梁与台阶并入底盘；紧凑端板保留四个完整电机座，底部两处锁紧点重排。接口资产及其校验文件未改动；按当前报告核对新增承压接触和完整内退／下取路径。

0.32将电机固定面重新融合进本项目底盘，取消独立端板及其锁紧件；接口资产仍未覆盖。维修改为先拆电源内托架和本侧履带，再卸四颗端面螺钉、向下取电机。前干舱隔板、水平内隔板及旧跨舱横梁删除，后湿舱隔板保留。

### 当前输出端间隙补充

2026-10-25 用户提供穿过固定面开口的电机输出端外径 **Ø11.9 mm**，并确认保留 **13 mm** 槽宽及顶部 **Ø13 mm** 圆弧。总名义间隙为 **13 − 11.9 = 1.1 mm**；居中时单边名义间隙为 **0.55 mm**。 这是用户尺寸与当前设计值的计算，不改写本目录的只读接口 BRep 或原回读记录。打印及实物适配仍待验证，尺寸来源见[电机记录](../37R-520/README.md#输出端开口配合2026-10-25)。
