# P01 双 MOS 开关模块实物

记录日期：2026-10-24。用户提供[正面](physical-front-20261024.jpg)和[背面](physical-back-20261024.jpg)照片，板背丝印 `JZ-MOS`。采购来源为[采购记录 P01](../../procurement.md)。照片原字节保存，来源及 SHA-256 见 [sources.json](sources.json)。

## 可直接确认的标识

| 丝印 | 接口含义／照片位置 |
|---|---|
| VIN+ | 输入正极；以背面照片方向为准，左上 |
| VIN− | 输入负极；背面左侧第二个端子 |
| VOUT+ | 负载输出正极；背面右上 |
| VOUT− | 负载输出负极；背面右侧第二个端子 |
| TRIG/PWM | 控制信号；以正面照片为准，底部四个小孔中的左侧一组 |
| GND | 控制信号地；正面底部四个小孔中的右侧一组 |

正反面翻转会交换左右，实物接线以丝印为准。正面可见每侧两个小孔之间的走线；这些是信号／地的重复接点，不是四个独立控制输入。较大的 J1 孔位不作为本轮接线定位依据。

照片中的控制小孔没有焊接排针，接线需焊接合适的排针或导线并检查无焊桥，不能将杜邦插针松插进裸孔当作可靠接触。全断电后进行焊接／改线。照片可见功率端已有线，但未展示另一端，不能据线色确认实际电源、负载、极性或上电状态。

## 拓扑与能力边界

既有商家图称双 MOS 并联的一路开关；背面可见 VIN+／VOUT+ 一侧连续的大面积铜区、两个负端分区，与低侧开关拓扑相符。这是照片推断，尚未用断电通断测量或原理图确认。当前负载为后置降压板，其 GND 应接 VOUT−；水枪负极接降压板 GND，不能另外接 VIN−／ESP32 GND 绕过开关。

MOS 器件完整型号未可靠辨认。商家标称工作电压 5–36 V、3.3–20 V 高电平触发不因这些照片改变；用户澄清实际是 5 V→MOS→降压板 3.7 V→水枪，MOS 输入为 5 V，不再套用此前 3.7 V 直供 MOS 的假设。照片不证明逻辑阈值、额定电流、导通压降、输入悬空／复位关断或感性负载保护。未取得续流／钳位器件的明确依据，不据外观认定已具备保护，也不直接断定没有保护。
